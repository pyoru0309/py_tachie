タイトル組版エディタ¶

タイトル組版エディタは、プロジェクト非依存の単体ユーティリティで、16:9 の透過可能なキャンバスにテキストレイヤーを自由に組んで PNG として書き出すための画面です。OP / EP のタイトル、章扉、ロゴ風コピー、ゴシックの「次回予告」など、本編シナリオに張り付くものではなくロゴとして再利用したい組版を作るのに向きます。

URL は /title-editor で、ダッシュボードやヘッダーからの導線とは別の独立ページです。データはプロジェクトを横断する title_compositions/<id>.json に保存され、ZIP アーカイブには含まれません (= 全プロジェクト共通の作業領域)。

画面構成¶

ブロック 役割
上部ツールバー タイトル名 / 既存組版を開く / 新規 / 保存 / 削除、PNG 保存先 / PNG 保存
キャンバス 1920×1080 のプレビュー。ドラッグで位置調整、選択枠は実 ink に密着
キャンバス下 背景色、背景透明 (PNG 書き出しで透過) のチェック、サイズ表示
右ペイン (整列ツールバー) 左右・上下・等間隔の整列ボタン (2 つ以上選択で有効)
右ペイン (レイヤー編集) 選択中レイヤーの全パラメータ (テキスト・位置・書体・カーニング・光彩・ドロップシャドウ・位置プリセット・回転)
右ペイン (レイヤー一覧) レイヤーの追加 / 複写 / 前面・背面 / 削除と、リストでの選択切替

レイヤー操作¶

レイヤーパネル右上のボタンと、全体設定で定義されたキーボードショートカットの両方から操作できます。複数選択の状態でも同じ操作がそのまま効きます。

操作 ボタン ショートカット 動作
新規レイヤーを追加 — キャンバス中央付近にデフォルト書体の空テキストを追加
選択を複写 Shift + D 元レイヤーの直後に同じ内容を挿入し、(+24, +24) ずらして配置。複写群が選択状態になる
前面 / 背面 へ移動 / — 配列内の前後関係を入れ替え (配列後方ほど画面手前)
選択を削除 Backspace 選択中のレイヤーを削除。Undo で復帰可
Undo / Redo — Cmd/Ctrl + Z / Cmd/Ctrl + Shift + Z タイトルエディタ独立の履歴
保存 Cmd/Ctrl + S サーバ側 title_compositions/<id>.json に保存

ショートカットは編集画面と同じ全体設定 (全体設定 → ショートカット) を読みます。Shift+D を別キーに割り当て直せば、タイトルエディタの複写もそのキーになります。

配置と整列¶

  • キャンバス上でレイヤーをドラッグすると、青い選択枠 (= 実 ink バウンディング) が表示されます。advance ベースの枠ではなく、書体ごとの 字面 に密着するので、明朝系で全角数字や約物が混じるタイトルでも視覚中心を捉えやすくなっています。
  • ドラッグ中は中央線と他レイヤーの ink 端 / 中央にスナップが効きます (Shift で一時無効化はしません。スナップを避けたい場合は座標入力で直接指定してください)。
  • 複数レイヤーを Shift + クリック または Cmd/Ctrl + クリック で追加選択し、整列ツールバーで左 / 中央 / 右 / 上 / 中央 / 下、3 つ以上では水平 / 垂直の等間隔配置にできます。整列も ink ベースなので、字面で揃って見える位置に揃います。
  • 位置プリセットは 3×3 グリッドで、選択中レイヤーの ink を画面端から 40 px の余白で寄せます。

テキストスタイル¶

レイヤー編集ペインで触れる主な項目です。

カテゴリ 項目
テキスト 本文 (改行可)、X / Y、文字サイズ、書体、太さ、回転
色 文字色、アウトライン色、アウトライン太さ
段組 文字揃え (中央・左・右)、文字間 (1/1000em)、行間
カーニング オプティカルカーニングの有無、高精度モード (低速)
光彩 有効 / 色 / ぼかし / 不透明度
ドロップシャドウ 有効 / 色 / ぼかし / X・Y オフセット / 不透明度

オプティカルカーニング・光彩・ドロップシャドウの内部実装は編集画面のテロップと完全に共通です (drawTextClip 経由)。本編のテロップで仕上げた見た目をそのままタイトル組版に持ち込めるよう、書体メトリクス・光彩 3 層化・ドロップシャドウのオフセット 0 ぴったり重ねまで一致した描画になります。

PNG 書き出し¶

上部ツールバー右端の PNG 保存 で書き出します。保存先は隣のセレクタで決めます。

保存先 出力位置 用途
ローカル ブラウザのダウンロード 手元保存・他ツールへの受け渡し
アセット共通 assets/foregrounds/<タイトル名>.png 全プロジェクトで使い回せる前景イラスト枠に登録
現行プロジェクト (前景) projects/<project_id>/assets/foregrounds/<タイトル名>.png 特定のプロジェクト専用素材

背景透明 を有効にすると背景塗りを抜いた状態で PNG 化されるため、本編のシーン上に重ねるロゴ・タイトルを切り出す用途で使えます。背景色を残せばサムネ用の差し込み画像にも向きます。

ポイント¶

  • タイトルエディタは編集画面とは独立した履歴 / 独立した保存場所を持ちます。本編シナリオを開き直しても作業中のタイトル組版は失われません。
  • 保存データ (title_compositions/<id>.json) はプロジェクト ZIP の対象外です。配布の際にタイトル組版も添える場合は手動で同梱してください。
  • 「位置プリセットや整列が思った中心と微妙にズレる」と感じた場合は、字面 (ink) と書体の幅 (advance) の差です。タイトルエディタは ink ベースで揃えているので、それが視覚上は正しい中心です。
