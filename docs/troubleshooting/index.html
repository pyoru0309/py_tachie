トラブルシュート¶

画面が開かない¶

サーバが起動しているか確認してください。

python3 -m app                    # 推奨 (内部で ws_per_message_deflate=False を強制)
python3 -m app --port 8001        # 別ポートで上書きしたいとき

ブラウザでは http://127.0.0.1:8000/ を開きます。 別のプロセスが 8000 番ポートを使っている場合は、上の --port で別ポートに切り替えて URL もそれに合わせます。

動画書き出しが極端に遅い (1〜10 fps しか出ない)¶

WebSocket の permessage-deflate が原因のことが多いです。python -m app で起動していれば自動で OFF になりますが、uvicorn を直接呼んでいる場合は次が必要です。

python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 \
    --ws-per-message-deflate false

websockets ライブラリが入っていないと WebSocket 自体が動きません。requirements.txt には個別に websockets を明記しているので、pip install -r requirements.txt で確実に入ります。

Windows で Activate.ps1 が実行できない¶

PowerShell の実行ポリシーで止められている可能性があります。次のいずれかで対処します。

# A. 一時的に Bypass で起動する
PowerShell -ExecutionPolicy Bypass

# B. コマンドプロンプトで activate.bat を使う
.\.venv\Scripts\activate.bat

素材が選択肢に出ない¶

素材を正しいフォルダに置いたあと、ヘッダーの 素材再スキャン を押してください。 背景・動画・音声・フォント・装飾 PNG・キャラクターの各フォルダと対応拡張子を確認してください。 共通素材 (assets/) とプロジェクト固有素材 (projects/<id>/assets/) のどちらに置いたかも確認します。

キャラクターが表示されない¶

次を確認します。

  • カット内にキャラクターが追加されている
  • キャラクターを表示 が有効になっている
  • base の素材 ID が選ばれている
  • 画像ファイルが PNG / WebP / AVIF として開ける
  • X / Y 座標と拡大率が画面外になっていない

白い部分が消えすぎる¶

白背景を透過扱いにする は #FFFFFF 完全一致のピクセルだけを透明化する簡易処理です。 白い服、白い髪飾り、ハイライトなどが消える場合は、透過 PNG として素材を書き出してください。

黒線がジャギジャギする / にじむ¶

純黒線画キャラなら、PSD インポータダイアログ下部の 黒線アンチエイリアス を ON にして取り込み直してください。 プリセットセレクタで「シャープ / 標準 / ソフト / マイルド / 太線対応」が選べます。絵柄や線の太さによって相性が違うので、同じ PSD を別 ID で複数回インポートして比較するのが手早いです。 詳しくは キャラクターモデル: 黒線アンチエイリアス を参照してください。

なお処理は素材 PNG に焼き込まれます (再生時のオン・オフは無し)。後から変えたいときは PSD を再インポートします。

口パクが動かない¶

次を確認します。

  • 設定画面の 口パク が有効になっている
  • カットに話者 (speakerCharacterId) が設定されている
  • 話者キャラのレイヤー編集で、口素材に 閉じ / 中間 / 開き (= lipClosed / lipMid / lipOpen) のフラグが立っている (最低 開き 1 つ)
  • 音声ファイルが存在しているか、シーンの BGM で useForLipSync が ON になっている
  • ffmpeg / ffprobe が利用できる

無音区間ではカット選択の口がそのまま表示される仕様です (lipMid 未設定なら mid 帯域もカット選択にフォールバック)。

目パチが動かない¶

次を確認します。

  • 設定画面の 目パチ が有効になっている
  • レイヤー編集で「目パチさせたい目」(普通目・驚き目など) に 開き (= blinkOpen) フラグが立っている
  • レイヤー編集で閉じ目素材に 閉じ (= blinkClosed) フラグが立っている (これが無いと目パチ自体が起きない)
  • カットで選んだ目が 開き フラグ付きである (笑い目・ウインク目を選んだカットは目パチがスキップされる仕様)

中間 (= blinkHalf) は任意で、無ければ「ぱちっと閉じてぱちっと開く」2 段目パチになります。

ffmpeg が見つからない / 「ffmpeg が利用できません」と出る¶

  • ターミナルで ffmpeg -version を実行できるか確認してください。コマンドが見つからない場合は ffmpeg がインストールされていない、または PATH に通っていません。
  • インストール手順は はじめに を参照してください。
  • macOS は brew install ffmpeg、Windows は winget install Gyan.FFmpeg がいちばん簡単です。
  • PATH に通せない場合は、立ち絵システムの 全体設定 → ffmpeg のパス に ffmpeg (Windows なら ffmpeg.exe) の絶対パスを指定すれば動きます。

動画書き出しに失敗する¶

  • 上記「ffmpeg が見つからない」を確認してください。
  • 書き出し中に Killed / OOM が出る場合は、長尺シーンを複数シーンに分割してください (動画書き出しは v2 GL レンダ → ffmpeg のワンパスで、ブラウザの WebGL コンテキストとサーバの ffmpeg プロセスが主なメモリ消費源)。
  • HW エンコーダで失敗する場合は、ffmpeg -encoders | grep nvenc などで該当エンコーダがビルドに含まれているか確認します。
  • 音声パスや背景パスが存在しない場合も失敗することがあります。素材再スキャン後、各カット / シーンの音声と背景を選び直してください。

書き出し時に NVENC / VideoToolbox が UI に出てこない¶

  • 全体設定の ffmpeg のパス を保存し直すと、ffmpeg -encoders のキャッシュが更新されます。
  • NVENC は GPL ビルドの ffmpeg に含まれます。LGPL ビルドだと表示されません。
  • VideoToolbox は macOS の標準 ffmpeg に含まれます。Linux / Windows では出ません。

フォントが反映されない¶

  • .otf / .ttf を assets/fonts/ か projects/<project_id>/assets/fonts/ に置きます。
  • ヘッダーの 素材再スキャン を押します。
  • ファイルがない場合はシステム既定フォントにフォールバックします。
  • ライブプレビューと書き出しで書体が違って見えるときは、ブラウザを再読み込みして FontFace 登録を更新してください。
  • 配布直後の assets/fonts/ は空です。最低限の日本語表示が必要なら、全体設定 → 環境 → Noto Sans JP をインストール を一度押してください。

フォントの太さ (weight) が思ったものにならない / セレクタに 1 種類しか出ない¶

立ち絵システムは assets/fonts/ 配下のフォントから OS/2.usWeightClass (フォント自身が申告する公式 weight 値) を読み取って太さを判定します。OS/2 が無い・壊れているフォントや、ベンダ独自の命名 (例: AwesomeFont-XYZ.otf の XYZ が weight 略号) で誤判定が出る場合は、全体設定 → 環境 → フォント自動認識 の表で各ファイルにドロップダウンから明示的な weight を割り当てられます。

  • 上書きは app_state/global_config.json の fontWeightOverrides ({相対パス: weight_id}) として永続化されます。
  • 保存後は自動で素材再スキャンが走り、新しい weight が右パネルのフォントセレクタに反映されます。
  • 「自動 (xxx)」を選び直せば override を解除できます。

動画レイヤーの音声が後半でズレる / 「再エンコードしますか？」と聞かれる¶

NVIDIA ShadowPlay などのゲーム録画 MP4 はフレームドロップ箇所で PTS (映像タイムスタンプ) が飛ぶことがあり、そのままだと動画レイヤーの音声が後半で実時間と数百 ms 単位でズレます。

立ち絵システムは動画レイヤーで素材を選んだ直後に PTS gap を検査し、合計 50 ms を超えるとダイアログで再エンコードを促します。

  • 推奨は ダイアログで「再エンコードする」を選ぶ。HW エンコーダ（VideoToolbox / NVENC / QSV / VA-API）が利用可能ならデフォルトで選択されており、実時間より高速で <元ファイル名>.fixed.mp4 が同フォルダに出力されます。
  • 元ファイルは残るので、再選択時は sidecar (<元ファイル名>.fixed.mp4.json) の SHA で「既に修正済み」と判定され、ダイアログは出ません。
  • キャンセル を選んだ場合は元ファイルのまま使えますが、書き出し時に音ズレ / apad はみ出しが残る可能性があります。

詳しい挙動は 編集画面リファレンス → 動画レイヤー編集パネル を参照してください。

オフラインで動かしたい (CDN を使いたくない)¶

three.js / mp4box.js は既定では static/vendor/ のローカル版を見て、無ければ jsdelivr CDN にフォールバックします。社内環境でインターネットを切る前に、ネットワークが繋がる環境で 1 回だけ全体設定 → 環境 → JS ライブラリのインストール を押してください。static/vendor/three/<ver>/ と static/vendor/mp4box/<ver>/ に展開され、以後は CDN 不要で起動できます。

CDN を使う チェックは「ローカル版があっても CDN を使う」モードです。デバッグ用なので通常は OFF のままで問題ありません。

プロジェクトを別環境に持って行きたい¶

各プロジェクトカードの アーカイブ ボタンで <タイトル>.splite.zip がダウンロードできます。別環境のダッシュボード上部の 読み込み ボタンで取り込めば、シナリオ・設定・固有素材が復元されます。

  • 古いスキーマ (例: v3) で書き出した zip を最新版で読み込んでも、自動で v4 に migration されます。
  • 共通アセット (assets/characters/<id>/) は zip に含まれません。完全コピーが必要なら、assets/ 自体を別途同期してください。

PSD インポートで差分が出ない / レイヤーが落ちる¶

  • レイヤー名が命名規則 (カテゴリ/ID または カテゴリ:ID、フォルダ構造) に沿っているか確認してください。
  • カテゴリは back_hair / base / cheek / eye / mouth / bangs / front の 7 種です。
  • 名前の先頭が _ のレイヤーは取り込み対象外です。
  • 複雑なレイヤー効果やクリッピングは作画ツール側でラスタライズしてから保存してください。
  • 縦横上限を小さく設定すると等倍縮小されます。元解像度を保ちたいときは 0 にしてください。

ライブプレビューが重い / もたつく¶

  • 動画背景 (videoTrack) が長い場合は、シーン分割を検討してください。
  • 全体設定の 静音モード を ON にすると uvicorn のアクセスログが抑制され、コンソール出力のオーバーヘッドが減ります。
  • 別プロジェクトに切り替える前に必ず再生を止めてください (内部的にも自動で停止しますが、明示停止の方がメモリの解放が早いです)。

音声合成 (VOICEVOX / VOICEPEAK)¶

VOICEVOX や VOICEPEAK の連携で問題が起きた場合は 音声合成 (VOICEVOX / VOICEPEAK) を使う を参照してください。よくある原因:

  • 全体設定 → 音声読み上げの「ボイスを登録」を 1 回も押していない (= カタログ未取得)
  • VOICEVOX が起動していない (立ち絵システム側から自動起動を試みますが、20 秒以上かかる環境では再ボタンが必要)
  • voice ID 形式が古い (voicevox:8 等)。「ボイスを登録」を押すと自動で voicevox:四国めたん/ノーマル 形式に再書き換えされます

Undo / Redo が効かない¶

  • Cmd/Ctrl+Z / Cmd+Shift+Z (または Cmd/Ctrl+Y) はテキスト入力中は OS のネイティブ動作 (フォーム単位の Undo) を優先します。タイムライン canvas など、フォーム外をクリックしてから操作してください。
  • 履歴サイズは全体設定で 1〜500 まで変更できます。長尺シナリオで履歴をたくさん残したいときは大きめにしてください。

起動はするが書き出しキャッシュが肥大化する¶

  • projects/<project_id>/cache/ は安全に削除して問題ありません。GL プレビューの中間 PNG (preview/) と口パク解析データ (lipsync/) は次回開いたときに必要分だけ自動再生成されます。
  • 手動で空にするには アセット管理ダイアログ → キャッシュ タブ を使ってください。プロジェクト別 / 共有 / 全削除のいずれかを選べます。thumbnail.png は削除対象から外れているのでプロジェクト一覧表示は壊れません。
  • 起動時に自動間引き する設定が既定で ON です (mtime が 30 日より古いものを削除)。期間は 全体設定 → キャッシュ タブで変更できます (1〜365 日)。
  • 書き出し時の中間ファイル (rawvideo パイプ) は処理が完了すると自動で消えます。途中で強制終了した場合は cache/ 以下に残骸が残ることがあるので、上記のキャッシュタブから掃除してください。

効果音をループ + 区間指定で使うと、書き出しで指定区間を超えて鳴り続ける¶

  • バージョン 2026-05-22 より前で、効果音に 「ループ ON」+「素材内の頭出し (audioOffsetSec > 0)」+「区間長 (durationFrame) が 素材残尺 - audioOffsetSec より長い」 という条件が揃ったときに、書き出し側で指定区間を最大「素材残尺」分だけ超えて鳴り続ける不具合がありました。プレビューでは正常に止まるため気付きにくい不具合です。
  • 現在は ffmpeg の -stream_loop -1 + 入力側 -ss の組合せをやめて、フィルタ側 atrim=start=offset:duration=region に切り替えることで解消しています。最新版に更新後、もし同様の症状に遭遇したら、当該プロジェクトを開き直して再書き出ししてみてください (シナリオ側に変更は不要です)。
