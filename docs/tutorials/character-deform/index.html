体の一部を動かす（伸縮・揺れピン）¶

立ち絵を動かす方法は、これまで「キャラ全体の位置を動かす」（モーション・体の揺れ）だけでした。体の変形 を使うと、キャラの絵の一部だけを動かせます。

機能 動き 向いている場面
体の伸縮 腰から上などの範囲だけが、リズムに合わせて縦に伸び縮みする 歌・ダンスでリズムを取る、弾むような喜び
揺れピン ピンを置いた髪・衣装の周りが、ふわふわ揺れる 髪やスカート、リボンが風になびく

どちらも、動かす場所 はキャラ詳細で決めて キャラの定義 に保存し、動かす量 はカットごとに決める、という分担です。一度場所を決めておけば、どのカット・どのプロジェクトでも同じ場所が動きます。

書き出しでも同じ動き

動きはシーンの経過時間から計算します。カットをまたいでも途切れず、シークしても書き出しても同じ形になります。光彩・ドロップシャドウも一緒に変形します。

体の変形の編集画面を開く¶

  1. ヘッダーの キャラ管理 で、キャラクターを選んで開きます（キャラ詳細）。
  2. 体の変形（伸縮範囲・揺れピン） 欄に、いまの設定の概要が出ています。変形を編集… を押すと、大きな編集画面が開きます。
  3. 上の 伸縮範囲 / 揺れピン で、編集するものを切り替えます。
  4. 編集が終わったら 反映して閉じる を押し、キャラ詳細の 保存 で確定します。

キャンセル（または Esc キー）を押すと、編集画面を開いたときの状態に戻ります。反映したけれどまだ保存していないときは、概要に「（未保存の変更あり）」と出ます。

表示の拡大縮小・移動¶

髪先など細かい場所は、拡大してから作業すると楽です。

操作 方法
拡大縮小 ピンチ / Ctrl（Mac は ⌘）+ ホイール（カーソルの位置を中心に拡大縮小）、または上部の − ＋ ボタン
表示の移動 2 本指スクロール / スペースキーを押しながらドラッグ / ホイール（中ボタン）でドラッグ
全体を表示 全体表示 ボタン

倍率の表示（例: 45%）は、絵の実寸に対する大きさです。

試しに動かす¶

試しに動かす を押すと、本番と同じ描き方で絵が動きます。もう一度押すと止まります。

  • 揺れピンは、実際の振れ幅のまま揺れます（カットの強さ 100% のとき）。
  • 伸縮範囲は、範囲を確かめるための控えめな動きです。実際の伸び縮みの大きさは、カットの体の揺れの 振幅 で決まります。

1. 体の伸縮¶

伸縮する範囲を決める¶

編集画面で 伸縮範囲 を選びます。絵の上に 2 本の線が出ます。

線 意味
基準線（腰） ここより下は動きません（足元は床に着いたまま）
上端（首） ここより上（頭）は、形を変えずに一緒に上下します。上端（首）を指定する をオンにすると出ます
  • 線はドラッグで動かします。線から離れた所を押すと、近い方の線がそこへ移ります。
  • 位置は数値（絵の上端からの %）でも入力できます。
  • 体積の保持 は、伸びたときに横を細く、縮んだときに横を太くする度合いです。0% にすると横幅は変わりません。
  • 既定に戻す で、「足元を基準に全身が伸縮する」状態に戻ります。範囲を決めていないキャラも、この既定で伸縮します。

上端を指定するかどうか

上端を指定しないと、基準線から頭のてっぺんまでが一様に伸びるので、顔も縦に伸びます。顔の形を保ちたいときは、首のあたりに上端を置いてください。

カットで伸び縮みさせる¶

伸び縮みは、体の揺れの 揺らし方 で「範囲を伸び縮みさせる」を選ぶと始まります。

  • キャラごと: キャラ配置タブの BPM 上下ゆれ → 揺らし方
  • シーン全体（全キャラ）: シーン設定の 体の揺れ タブ → BPM ボブの揺らし方

振幅 (px) は、伸縮範囲の上端（上端を指定していなければ頭のてっぺん）が何 px 動くかになります。動き（波 / 跳ねる / 沈む）・溜め・リズム・BPM の取得・口パクのときだけ揺らす、はそのまま使えます。「沈む：うなずき」なら、拍で縮みます。

位置の揺れと組み合わせる

シーン全体の BPM ボブを「全身の位置」、キャラの BPM 上下ゆれを「範囲の伸縮」にするなど、2 つを組み合わせることもできます。

2. 揺れピン¶

ピンを置く¶

編集画面で 揺れピン を選び、クリックで追加するピン で種類を選んでから、絵の上をクリックします。

ピン 表示 働き
揺れピン 実線の円 + 揺れる向きの矢印 円の中が揺れます。中心ほど大きく、縁に近いほど小さく揺れます
固定ピン 赤い点線の円 + 中心の四角 円の中は揺れません。近くの揺れピンの揺れを打ち消します
  • ピンはドラッグで動かします。
  • 大きさは、選択中のピンの右端にある白いつまみ（または円の縁）をドラッグして変えます。
  • 新しいピンは、画面上でおよそ同じ大きさになるように置かれます。拡大して置くと小さなピンになります。
  • 1 キャラにつき 16 本まで置けます。

円にかかった所はすべて動きます

揺れピンは「髪」だけを選んで動かすのではなく、円の中の絵 をまとめて動かします。髪と腕や胴体が同じ円にかかると、腕や胴体も揺れます。揺れてほしくない所（顔・腕・胴体など）には 固定ピン を置いて押さえてください。

ピンの設定¶

ピンを選ぶと、横の 選択中のピン 欄で値を変えられます。

項目 説明
種類 揺れ / 固定
大きさ (%) 影響する円の半径（絵の高さに対する %）
振れ幅 (%) 揺れる幅（円の半径に対する %）。大きすぎると絵が崩れるので 40% まで
向き (°) 揺れる向き。0 で左右、90 で上下
周期 (秒) 1 往復にかかる秒数
位相 (%) 揺れ始めのずれ。ピンごとにずらすと、なびいて見えます

固定ピンは位置と大きさだけを使います。

まとめて変える¶

複数のピンを選ぶと、欄で変えた値が 選択中のピンすべて に入ります。

  • Shift / ⌘ クリック で、ピンを選択に足したり外したりできます。
  • すべて選択（⌘A）・揺れピンだけ・選択解除 のボタンもあります。
  • 値がばらばらな欄は空欄（「混在」）になります。そのまま触らなければ、それぞれの値が残ります。
  • 位相を順にずらす を押すと、選択中の揺れピンの位相が上から順に少しずつずれます。毛先へ向かって波が伝わるような、なびく動きになります。
  • 選択中のピンはドラッグでまとめて動かせ、Delete キーでまとめて消せます。

カットでの強さ¶

揺れピンを置いたキャラは、どのカットでも揺れます。カットごとの強さは、キャラ配置タブの 髪・衣装の揺れ（揺れピン） → 揺れの強さ (%) で変えます。

  • 100% でキャラ詳細の設定どおり、0% で止まります。300% まで強くできます。
  • 揺れピンの無いキャラには効きません。

困ったとき¶

  • 伸び縮みしない — 揺らし方が「範囲を伸び縮みさせる」になっているか、振幅が 0 より大きいか、BPM が取れているか（手入力で 0 になっていないか）を確認してください。
  • 顔まで伸びる — 伸縮範囲の 上端（首）を指定する をオンにして、首のあたりに置いてください。
  • 腕や体まで揺れる — 揺れピンの円が腕や体にかかっています。ピンを小さくするか、揺れてほしくない所に固定ピンを置いてください。
  • 揺れが大きすぎて絵が崩れる — 振れ幅を下げるか、カットの揺れの強さを下げてください。
  • キャラ詳細で変えたのにプレビューが変わらない — キャラ詳細の 保存 を押したか確認してください。編集画面の「反映して閉じる」だけでは保存されません。

設定の保存先¶

変形の場所はキャラ定義（character_manifest.json の deform）に保存され、配布用の import_manifest.yml にも書き出されます。PSD を取り込み直しても消えません。カットごとの値は、シナリオのキャラ設定（bob.target / sway.strength）に入ります。詳しくは シナリオデータ仕様 を参照してください。
