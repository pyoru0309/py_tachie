歌・デュエットの口パク¶

歌ってみた動画や MV では、従来の「話者 1 人の口を音量で動かす」口パクだけでは足りない場面があります。

  • デュエット曲 — 2 人が交互に・同時に歌うので、キャラごとに別の音声で口を動かしたい
  • 伸ばす音・ブレス — 音量だけで判定すると、ロングトーンの減衰で口が閉じたり、息継ぎで口が動いたりする

立ち絵システムでは次の 2 つの方法で、キャラクターごとに口パクを割り当てられます。どちらもシーン設定の BGM タブで、BGM トラックごとに設定します。

方法 入力 向いている素材
キャラ別の口パク入力 キャラごとのボーカル音声 (wav 等) の音量 ボーカルをキャラ別に書き出してある
歌唱判定 MIDI ボーカルのノート + 歌詞 (かな) カラオケ採点・歌声合成用の MIDI がある。口形 (あいうえお) まで合わせたい

どちらを使うか

MIDI があるなら MIDI がおすすめです。ノートの長さがそのまま「口を開けている時間」になり、歌詞から母音の口形も選ばれるので、音量判定より正確です。両方を設定したキャラは MIDI が優先されます。

1. キャラ別の口パク入力 (デュエット)¶

  1. ボーカルをキャラごとに書き出した音声 (例: 曲_マキ.wav / 曲_モカ.wav) を BGM として追加します。伴奏は別の BGM トラックにします。
  2. ボーカルのトラックで このトラックを口パク入力に使う（出力には流さない） を ON にします。
  3. 下に出る 口パクさせるキャラ で、そのボーカルのキャラにチェックを入れます。

チェックを入れたキャラは、話者かどうかに関係なく、そのトラックの音量で口パクします。2 人が同時に歌う区間では 2 人とも口が動きます。

  • 口パク入力のトラックは出力 (プレビューの音・書き出した動画) には流れません。聞かせる音は伴奏 + ミックス済みボーカルなど、別トラックで用意してください。
  • キャラを 1 人も選ばないトラックは、従来どおり「話者の口パク」に使われます (シーン内 1 本まで)。
  • カットに話者音声 (セリフ) があるときは、そのカットの話者はセリフ音声で口パクします。

2. 歌唱判定 MIDI で口パク¶

MIDI の用意¶

ボーカルのパートごとに トラックを分けた Standard MIDI File (.mid) を用意します。各ノートに 歌詞イベント (ひらがな / カタカナ / ローマ字) が付いていると、口形 (あ・い・う・え・お・ん) まで反映されます。

  • テンポ変更は MIDI のテンポマップどおりに秒へ換算されます。
  • 歌詞の文字コードは UTF-8 / Shift_JIS のどちらでも読めます。
  • 歌詞の無いトラックは、全ノートを「あ」(= 口開け) として扱います。

設定¶

  1. シーン設定 → BGM タブで、その曲の BGM トラック (MIDI と同じ時間軸の音源) を開きます。
  2. 歌唱判定 MIDI で口パク の MIDI を追加 から .mid をアップロードするか、プルダウンから選びます (プロジェクトの assets/midi/ に保存されます)。
  3. MIDI のトラック一覧 (ノート数・歌っている時間・歌詞の冒頭) が出るので、トラックごとに口パクさせるキャラにチェックを入れます。
    • 1 人に複数トラック、1 トラックに複数キャラ (ユニゾン) も割り当てられます。
    • キャラ専用の口パク入力 (ボーカル音声、上の 1.) も設定してあると、割り当てを取り違えていないか を自動で確かめます。MIDI のノート中にそのキャラのボーカルが 15% を超えて無音なら、トラックの下に ⚠ 警告が出ます (別のキャラの音声の方が合っていればその一致率も表示)。オフセットが大きくずれていても出ます。
  4. 必要なら オフセット (ms) でタイミングを合わせます。

タイミング合わせ (オフセット)¶

MIDI の時刻は、その BGM トラックの 音源ファイルの時刻 に対応させます (BGM の「トリム開始」も自動で反映されます)。

  • + で口パクが遅れ、− で早まります。
  • 完成音源の頭を X ms 削ってある (MIDI は削る前の時間で作られている) 場合は −X を入れます。例: 100BPM・4/4 のダミー 1 小節 (2400ms) を除いて書き出した音源なら −2400。
  • BGM の「トリム (ms)」は音源側の頭出しです。MIDI はトリム後の音源位置に合わせて動くので、音源と MIDI のずれは MIDI のオフセットで、再生開始位置はトリムで、と別々に合わせられます。
  • 停止中はシーク位置の口形がプレビューに出ます。 歌い出しのカットで再生ヘッドを動かしながら合わせると確実です。

口の動き方¶

歌詞 口形
あ段・え段・い段・う段・お段 その母音 (「じゃ」→ あ、「きょ」→ お)
ん 閉じる
っ う
ー (長音)・歌詞の無いノート 直前の母音を伸ばす
ま行・ば行・ぱ行 ノートの頭で一瞬唇を閉じてから開く
「かん」のように末尾が ん ノートの終わりで閉じる
休符 カットで選んだ口

ごく短い休符 (70ms 未満) は前のノートをつないで、口がパタパタしないようにしています。

3. 口の絵の枚数と対応付け¶

口パクで使う口の絵は、キャラの レイヤー編集 で口レイヤーにフラグを立てて指定します。MIDI 口パク用に あ / い / う / え / お のフラグがあり、1 枚に複数立てられます。絵の枚数に合わせて、次のどのパターンでも動きます。

口の枚数 フラグの立て方 母音の割り当て
6 形 あ / い / う / え / お を 1 枚ずつ + 閉じ そのまま (ん・っ以外の閉じは「閉じ」)
4 形 「あ/え」の口に あ + え、「い」に い、「う/お」に う + お、「ん」に 閉じ あ・え / い / う・お / ん
3 形 口開け = 開き、口半開け = 中間、口閉じ = 閉じ (母音フラグなし) あ・え → 開き、い・う・お → 中間、ん → 閉じ
2 形 口開け = 開き、口閉じ = 閉じ あいうえお → 開き、ん → 閉じ

母音フラグが無い母音は、自動で近い口に寄せます (え → あ → 開き、う ↔ お → 中間 → 開き、い → 中間 → 開き)。従来の音量口パク用に作ったキャラ (開き / 中間 / 閉じ) は、そのまま 3 形として MIDI 口パクに使えます。

目パチ・コマ打ちとの関係

MIDI 口パクも目パチと同じく キャラアニメ fps (全体設定、8 / 12 / 24) でコマ打ちされます。

音量メーター

プレビュー下の音量メーターに出す音声は、BGM カードの 音量メーターに反映する（プレビュー） で 1 本選べます。口パクに MIDI を使っていても、ボーカルの音量を確認できます。

4. リズムに合わせて体を揺らす¶

シーン設定の 体の揺れ タブ (全キャラ) と、キャラの BPM 上下ゆれ (キャラごと) で、歌に合わせて体でリズムを取らせられます。

  • 動き を「跳ねる：なめらか / ジャンプ / キック」や「沈む：うなずき」にすると、1 周期のうち 溜め (%) の間は静止し、拍の頭で動きます (＿＿＿■＿＿＿■)。「波」は従来どおり常に揺れます。
  • リズム で BPM の倍 / 半分 / ¼ に変えられます。
  • BPM の取得 → MIDI から自動検出 にすると、BGM の歌唱判定 MIDI のテンポ (途中のテンポ変更も) に合わせます。キャラの揺れは、そのキャラを割り当てた MIDI を使います。「半分」なら 180→220 のテンポ変化は 90→110 の揺れになります。
  • 口パクのときだけ体を揺らす を ON にすると、そのキャラが歌っている (MIDI のノートがある / ボーカルに音がある) ときだけ揺れます。休符が続くと 1 周期あとに止まります。

困ったとき¶

  • 口が動かない — キャラにチェックが入っているか、口レイヤーに「開き」(または あ〜お) のフラグがあるか、全体設定の口パクが ON かを確認してください。
  • 口パクが全体にずれる — オフセットを調整してください。BGM の「トリム開始」を変えた場合は MIDI も自動で追従します。
  • BGM をプロジェクト通しにしている — MIDI の時間はプロジェクト先頭 (= BGM の再生開始) からで数えます。シーンごとの BGM ならシーン先頭からです。
