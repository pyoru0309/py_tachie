WebGL → readPixels → WebSocket → ffmpeg stdin の搬送限界を測定します。 まず discard で WS/ASGI 経路だけの throughput を見て、その上で -f null - → 実エンコーダ (libx264 / videotoolbox / nvenc) と段階を上げます。
backpressure 閾値を 0 にすると WS キューに無制限に積めます（= 旧挙動。enqueue fps が出るだけ）。 非 0 にすると bufferedAmount がそれを超えている間 ws.send を await して 実 throughput を測ります。
WS 圧縮が有効だと raw RGBA を毎フレーム deflate しようとして CPU が負けます。 uvicorn は既定で permessage-deflate を有効にする実装があるので、ベンチ用には --ws-per-message-deflate=false を付けて起動するのを推奨。 handshake で交渉された extensions は集計欄に出します。
