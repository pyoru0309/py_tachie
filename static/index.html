編集中のキャラクター

配置プリセットは編集中のキャラの X / Y / 拡大率 だけを覚えます。表情プリセットとは独立しているので、適用しても表情・髪型・前面オブジェクトは変わりません。

前面オブジェクト

モーション

編集中のキャラに対して動作を設定します (キャラごとに個別保存)。

編集中のキャラを開始 (X, Y) から終了 (X, Y) へ補間移動します。座標はキャラの基準位置からの相対オフセット、拡大率はキャラ拡大率に対する乗算係数 (1.0 = 等倍)、透明度・角度は絶対値です。基準 (X, Y) は回転・拡大の中心点 (1920×1080 絶対座標)。「計算」は表示時間の終わりまでを持続フレームに設定します。「指定」ボタンを押すとプレビュー上のクリック/ドラッグで基準点を指定でき、「決定」で確定します。

BPM 上下ゆれ

編集中のキャラを、BPM のビートに合わせて上下にゆらします（bob = 浮き沈み）。BPM・振幅のどちらかが 0 のときは無効です。動作モーションと併用できます（揺れながら移動・拡大など）。位相はシーン全体で連続します。

キャラを追加

キャラを置換

配置済みキャラを別キャラに置換します。X / Y / 拡大率 / 前後関係 / 左右反転 / 白透過は保持され、ベース・表情・髪型は新キャラの初期値に戻ります。

背景・場面

            

              
              
              
              
            

            

              
              
            

            

              
              
            

            

              
              
              
            

            

              
              
            

            
前景 / 背景の X / Y は画像の左上の表示位置です（0,0 = 画面左上、キャラの座標と同じルール）。空欄のときは中央に配置します。拡大率は前景が「画面に収まるサイズ」、背景が「画面いっぱい（1920×1080）」を 1.0 とした倍率です。ケンバーンズでズームアウトさせるときは、あらかじめ 1.1〜1.3 程度に上げて余白を作っておくと画面端が透けません。

            

              
              
            

            
背景画像が未指定のときに表示される色です（既定は完全透明）。背景画像を指定するとそちらが優先されます。

            

              
            

          


          

            
ケンバーンズ（シーン全体のズーム・パン）

            
            

              
              
              
            

            

              
              
              
            

            

              
            

            

              
              
              
            

            
カットの先頭から末尾までをかけて、シーン全体（背景・前景・キャラ・動画レイヤー・ビジュアライザー）をゆっくり拡大・移動させます。セリフ枠とテロップは対象外で、画面に固定されたままです。
拡大率は画面中央を基準にした倍率（1.0 = 等倍）、X / Y は平行移動量（px。X を正にすると絵が右へ動きます）です。ズームアウト（例: 1.2 → 1.0）では画面端に余白が出るため、上の「前景 / 背景 拡大率」であらかじめ大きめに敷いてください。

          


          

            
トランジション（カット入り）

            

              
              
              
              
            

            
直前カットの末尾と このカットの先頭で、効果時間を半分ずつシェアしてつなぎます（境界をまたぐので両カットが動いたまま切り替わります）。先頭カットでは「ホワイトアウト＝白から」「ブラックアウト＝黒から」のフェードインになります。
発話ディレイは、このカットの話者音声を冒頭から指定秒だけ遅らせます（トランジション中に声が出始める不自然さを避けるのに使います）。

カットを一括追加

            
現在のカットの後ろに、同じキャラ配置で複数のカットを追加します。

          

        

        

          

            
            
            
          

          
          
          

          

            

              改行区切りの場合、現在の話者で一括登録されます。「話者ID:セリフ」「話者名:セリフ」形式では、現在のカットに配置中のキャラクターに自動で話者を割り当てます（同名の話者が複数いる場合は前面側のレイヤーが優先されます）。区切り文字は半角「:」と全角「：」のどちらでも構いません。
            

            
            

              
              
            

            

              「音声を自動で作成する」が ON のとき、各カットの表示時間を「音声長 + 指定秒数」に拡張します。
            

          


          

            

              プロジェクトに登録済みの音声ファイル名が「連番-セリフ{-任意の文字列}.wav」形式であれば、一括登録可能です。話者は現在のカット位置と同じです。
            

            

          


          

            
            

              「セリフ書き出し」と互換のフォーマットに、voice / pause_sec を加えて指定できます。
              voice はアプリ名 prefix 付きで voicevox:四国めたん/ノーマル や voicepeak:Miyamai Moca、感情込みは voicepeak:Miyamai Moca/honwaka のように書きます。
              voice が無いものは音声生成をスキップ、感情が話者にない場合はノーマルにフォールバックします。

テロップ一括追加

            
新規入力は「テキスト」タブから、エクスポートを加工して戻すときは「YAML」タブから取り込めます。

          

        

        

          

            
            
          


          

            
改行区切りで入力した各行を、再生ヘッドから順番に追加します。

            

              
              
              
            

            
            
開始位置は再生ヘッドです。書体や色は「テロップを追加」と同じデフォルトを使います。

          


          

            

              「テロップ書き出し」と互換のフォーマットを取り込みます。start_sec / duration_sec / text をそのまま使い、style を書けば 1 つだけ書体・色も上書きできます。

              既存のテロップは置き換えず、追加されます。エクスポートを加工して戻すときに便利です。

動画書き出しプリセット

              
「動画出力」で使用するプリセットを選択します（内蔵プリセットは固定設定）

              

              

              

                
              

              
音声・書き出し挙動

              

                

                  
                  
編集ソフトに取り込んだ際のチャネル不一致を回避します（推奨）。

                

                

                  
                  
ONにすると「動画出力」ボタンを押した時にダイアログが開き、プリセット／FPS／品質設定を毎回選べます。OFFのときは前回のプリセットでそのまま書き出します。

                

              

              
動画書き出しの WebSocket バックプレッシャ (MB)

              

                ブラウザ → ffmpeg のフレーム送信で ws.bufferedAmount がこのサイズを超えたら送信を待機します。
                既定 16MB は長尺 (例: 5000 frame 超) を完走させるための安全側の値。
                スループットを上げたい場合は 32 / 64 を試してください。値を上げ過ぎるとブラウザのメモリが膨らみ、長尺でタブが落ちます。
              

              

                
              

            

            

              
編集履歴 (Undo / Redo)

              
編集中の Undo/Redo で覚えておく履歴の最大件数（1〜500）。リロードやプロジェクト切替で履歴は破棄されます

              

                
              

              
プレビュー再生

              
再生中、現在のカットから先読みするカット数（0〜20）。大きくするとカット境界の引っかかりが減りますが、ビジュアライザや背景動画など重い構成では前倒しで bake が走るため負荷が上がります。標準は 3。

              

                
                
              

              
標準は「シャープ」。Windows 等でジャギーが気になる場合は「滑らか」を選ぶと、毎フレーム高品質バイリニア縮小が掛かり輪郭が滑らかになります（書き出し品質には影響しません）。

            

            

              
ffmpeg バイナリのパス

              
空欄にすると環境変数 PATH から検出します。複数バージョンを使い分ける場合は絶対パスを入力してください。

              

                
              

              

              
プロジェクトフォルダの場所

              
空欄にするとアプリ同梱の projects/ を使います。外部ディスクなどへ移したい場合は絶対パスを入力してください（既存プロジェクトの自動移行は行いません）。

              

                
              

              

              
ログの抑制

              
ターミナルに流れるアクセスログ（毎カット切替の /api/v2/scene-bundle など）を抑制します。動画書き出し中は本設定にかかわらず常にエラー以外を抑制します。

シナリオの自動バックアップ

              

                scenarios/main.json を周期的にスナップショットします。
                プロジェクト切替時とダッシュボード復帰時にも自動取得されます。
                auto バックアップは古い順に削除 (世代管理) されますが、
                manual (「バックアップ」ボタン) と preRestore (復元前の安全網) は
                ここでは削除されず、プロジェクト設定 → バックアップタブからのみ削除できます。
              

              

                
                
              

              

                例: 5 分 × 50 件 = 直近 250 分 (約 4 時間 10 分) を遡れます。manual / preRestore は件数に含まれません。
              

            

            

              
キャッシュの自動間引き

              

                projects/<id>/cache/preview/ (プレビュー描画の中間 PNG) と
                cache/clean_pcm/ (録画素材音声) を、起動時に mtime ベースで間引きます。
                削除されたファイルは次回開いたときに必要分だけ自動再生成されるため安全です。
                手動の全削除は「アセット管理」→「キャッシュ」タブから実行できます。
              

              

                
                
              

              

                例: 6 時間 = mtime が 6 時間より古いファイルだけ削除。現在使用中のキャッシュは触れません。
                既定 6 時間。長時間の連続編集でキャッシュが数 GB 規模に膨らむため、短めに設定しても再生成コストは体感差ありません。

髪型プリセット (アセット定義)

            

          

        

        

          ベース・前髪・後ろ髪を組み合わせて名前付きで保存します。プロジェクトのお芝居タブの
          「髪型」セレクタはここで定義したプリセットを参照します。
          「デフォルト」に印を付けたプリセットは新規キャラ追加時に自動適用されます。
          髪型プリセットはアセット定義のみで、各プロジェクトでの個別上書きはできません。
        

        

        

          
          
        

        

          
          
        

      

    
    
      

        

          

            
表情プリセット (アセット定義)

            

          

        

        

          各プロジェクトでも表情プリセットを上書き保存できますが、ここで保存したものは「アセット定義」として
          すべてのプロジェクトに自動で読み込まれます。同名 ID のプリセットはプロジェクト側が優先されます。
          「デフォルト」に印を付けたプリセットは新規キャラ追加時に自動適用されます。

動画書き出し設定

            
このカット書き出しで使用するフォーマットと品質を指定します

          

        

        

          

            
            

            
            

            

              
              
              
              
            

            

              
              
ブラウザ内で H.264 に圧縮してから送るため、特に Windows で書き出しが大幅に速くなります。H.264 mp4 プリセットのときだけ有効で、透過 (ProRes/PNG) や非対応ブラウザでは自動的に従来方式に切り替わります。書き出し結果に問題が出る場合は OFF にしてください。

              
              
OFF にすると映像のみのファイル（音声トラックなし）で出力します。透過素材をカット単位で書き出して動画編集ソフトに取り込むとき、音声トラックが無い方が都合が良い場合に使ってください。
