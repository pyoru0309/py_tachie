# キャラクターモデルの推奨構成

立ち絵システムのキャラクターモデルは、7 つのカテゴリ (`back_hair` / `base` / `cheek` / `eye` / `mouth` / `bangs` / `front`) を組み合わせて 1 体の立ち絵を描画する素材セットです。
複数キャラクターを同じカットに配置できるため、各キャラクターは独立した素材ディレクトリとして管理します。

## 推奨ディレクトリ

```text
assets/characters/<character_id>/
  character_manifest.json
  thumb.png                  (任意。一覧表示のサムネイル)
  import_manifest.yml        (任意。配布用マニフェスト。レイヤー編集 / プリセット保存時に自動生成される)
  expression_presets.json    (任意。アセット単位の表情プリセット定義)
  hairstyle_presets.json     (任意。アセット単位の髪型プリセット定義)
  back_hair/
    ロング.png
  base/
    通常.png
    制服_ポーズ1.png
  cheek/
    赤味.png
  eye/
    眉_普通-眼_普通.png
    眉_普通-眼_閉じ.png
    眉_笑い-眼_笑い.png
  mouth/
    口_閉じ.png
    口_お.png
    口_あ.png
  bangs/
    通常.png
  front/
    手_正面.png
    汗.png
```

ファイル名・レイヤー名は自由 (元の PSD レイヤー名がそのまま残ります)。目パチ・口パクの対象判定は別途 `flags` (後述) で行うため、ファイル名を `open.png` のように特別な形に揃える必要はありません。

プロジェクト固有キャラの場合は、`projects/<project_id>/assets/characters/<character_id>/` 配下に同じ構造で置きます。

## 7 カテゴリの役割

| カテゴリ | 役割 |
| --- | --- |
| `back_hair` | 後ろ髪差分。`base` よりも下層に描画される |
| `base` | 顔・体・服・ポーズをまとめた立ち絵本体 |
| `cheek` | 頬染め、汗、ハイライトなど顔の補助表現 |
| `eye` | 目差分。目パチに使用 |
| `mouth` | 口差分。口パクに使用 |
| `bangs` | 前髪差分。`eyeAboveBangs` カットフラグで目との前後関係を切替 |
| `front` | 手・小物・サングラス・エフェクトなど。1 カットに複数同時表示可 |

## 合成順

1 体ぶんの立ち絵は次の順で重ねます。

1. `back_hair` (`base` より下)
2. `base`
3. `cheek`
4. `eye` (※ `eyeAboveBangs=true` のときは `bangs` の後にずれる)
5. `mouth`
6. `bangs` (※ `eyeAboveBangs=true` のときは `cheek` と `eye` の間に挿入)
7. `front` (複数指定可)

その後、シーンレベルの順番で次のように重なります。

1. シーンの `videoTrack` または `cuts[].state.background`
2. キャラクター 0..N (上記の順番で各 1 体ぶん)
3. セリフ枠 (`textStyle`)
4. テロップ (シーン全体に対して任意区間で配置)

## 最小構成

最小構成は `base/` の画像 1 枚だけです。ただし、自然な表情変更や動画用の目パチ・口パクを使う場合は、`eye/` と `mouth/` を 2 種類以上用意してください。

## 目パチ・口パク用のフラグ {#blink-lipsync-flags}

レイヤー単位で **フラグ** を立てて、どの素材を目パチ・口パクのどの状態に使うかを明示します。
ファイル名・レイヤー ID は変更せず、`character_manifest.json` の各エントリに `flags` フィールドが追加される形で保存されます。

| カテゴリ | フラグ | 役割 | 排他 |
| --- | --- | --- | --- |
| eye | `blinkOpen` | 「このレイヤーを選んだカットでは目パチを動かす」マーク。複数立てて OK (キャラごとに「普通目」「驚き目」など複数が目パチ対象になる) | × |
| eye | `blinkHalf` | 半目 (中間フレーム) | ○ (シーン全体で 1 枚) |
| eye | `blinkClosed` | 閉じ目 (閉じフレーム) | ○ (同) |
| mouth | `lipClosed` | 閉じ口 (口パク用) | ○ |
| mouth | `lipMid` | 半開き口 | ○ |
| mouth | `lipOpen` | 開き口 | ○ |

### 目パチの動作ルール

- **カットで選択した目に `blinkOpen` が立っているとき**だけ目パチが発動します。`blinkOpen` のない目 (例: 笑い目・ウインク目) を選んだカットでは、目パチをスキップして選択中の表情をそのまま維持します。これで「逆アーチ状の目パチが笑顔から飛び出す」ような不自然な動きを避けられます。
- 目パチ中の中間/閉じフレームは、`blinkHalf` / `blinkClosed` フラグが立った 1 枚を共通で使います。
- `blinkClosed` のみ設定して `blinkHalf` を未設定にしている場合は、半目に閉じ目を流用した **2 段目パチ** にフォールバックします (アニメ表現上は「ぱちっと閉じてぱちっと開く」)。

### 目パチのフレーム配分 {#blink-frame-pattern}

プロジェクト設定の **アニメ fps** (`characterAnimationFps`、既定 12) と **目パチ方式** (`blinkAlgorithm`、既定 `アニメ方式`) に従って次のサイクルで動きます。書き出し fps とは独立した量子化基準なので、24fps 出力時でも「3 コマ割り風の blink」を表現できます。

#### アニメ方式 (既定)

アニメ業界の鉄則「開き → 閉じ → 中 → 開き」(スナップ閉じ + 段階開き) に揃えた配分です。閉じ目の滞在を長めに取り、半目を経由してゆっくり開けることで「ぱちっ」とした自然な瞬きになります。

| アニメ fps | 中目あり | 中目なし |
| --- | --- | --- |
| 8 fps (3コマ割り) | 開き → 閉じ → 中 → 開き | 開き → 閉じ → 閉じ → 開き |
| 12 fps (2コマ割り) | 開き → 閉じ → 閉じ → 中 → 開き | 開き → 閉じ → 閉じ → 閉じ → 開き |
| 24 fps (フル) | 8コマ割りを 3 回繰り返し (閉じ ×3 → 中 ×3) | 同 (閉じ ×6) |

#### 均等方式

各 fps で短く均等な目パチを打ちます。中目あり/なしでパターン長そのものが変わり、中目なしのキャラはより短い瞬きになります (= 「眠そう」感を抑えてキビキビ動く)。

| アニメ fps | 中目あり | 中目なし |
| --- | --- | --- |
| 8 fps (3コマ割り) | 開き → 閉じ → 中 → 開き | 開き → 閉じ → 開き |
| 12 fps (2コマ割り) | 開き → 閉じ → 中 → 開き | 開き → 閉じ → 閉じ → 開き |
| 24 fps (フル) | アニメ方式と同じ (閉じ ×3 → 中 ×3) | 開き → 閉じ ×3 → 開き |

両方式とも、`blinkHalf` 未設定キャラは **「中目なし」** 列のパターンに自動で切り替わります (シーン内で混在 OK)。

### 口パクの動作ルール

- 話者キャラ (`speakerCharacterId` が指す登場キャラ) のみ動きます。それ以外のキャラはカット選択の口がそのまま出ます。
- 話者音声 (`cut.audio`) または シーン BGM の `useForLipSync` トラックの音量を解析し、`silenceThreshold` / `openThreshold` で 3 段階に分類します。
    - 音量 ≥ open 閾値 → `lipOpen` フラグの口
    - silence 閾値 ≤ 音量 < open 閾値 → `lipMid` フラグの口
    - 音量 < silence 閾値 / 音声なし / 全体設定で口パク OFF → **カット選択の口** をそのまま表示
- `lipMid` フラグ未設定なら mid 帯域も `lipOpen` ではなく **カット選択の口** にフォールバックします。
- 「話している間だけ口パクが乗り、無音区間や口パク OFF ではカット指定の表情がそのまま見える」挙動です。例えば「ジト目で `:|` のような口」を意図的に選んだカットは、無音区間でその口が維持されます。

### フラグの設定方法

1. 編集画面の **キャラ管理 → レイヤー編集** ダイアログを開く。
2. eye / mouth セクションの各レイヤー行にチェックボックスが並ぶ。
3. 立てたいフラグを ON にして保存する (`blinkHalf` 等の排他フラグは他レイヤーから自動的に外れる)。

カット編集の `目` / `口` セレクタでは、フラグが立ったレイヤーが「眉_普通-眼_普通（開き）」のように **末尾の括弧** で識別できる形で表示されます (`name` フィールドは元の PSD レイヤー名のまま、UI 表示のみ装飾)。

## eyeAboveBangs

通常絵では前髪 (`bangs`) が目の前に重なりますが、目だけ前髪より上に出したい演出のときはカット単位で `eyeAboveBangs` を ON にします。
編集画面のキャラ配置タブで切り替えられ、`scenes[].cuts[].state.characters[].eyeAboveBangs` として保存されます。

## 髪型プリセット (hairstyle preset) {#hairstyle-presets}

ベース・前髪・後ろ髪の 3 つの組み合わせを **名前付き** で保存して、カット内で 1 個のセレクタから選べるようにする仕組みです。`assets/characters/<character_id>/hairstyle_presets.json` がデータ実体で、アセット定義のみで完結します（プロジェクト固有の上書きは持ちません）。

```json
[
  {
    "id": "long",
    "name": "ロング",
    "isDefault": true,
    "baseId": "base_制服_デフォルト",
    "bangsId": "bangs_通常",
    "backHairId": "back_hair_ロング"
  },
  {
    "id": "short",
    "name": "ショート",
    "isDefault": false,
    "baseId": "base_制服_デフォルト",
    "bangsId": "bangs_短め",
    "backHairId": ""
  }
]
```

### プロジェクト編集での挙動

- カット編集パネルの「髪型」セレクタにプリセット一覧が表示されます。`isDefault: true` のプリセットは `★` 付きで表示され、新規キャラ追加時に自動選択されます。
- カット内のキャラには `hairstylePresetId` だけが保存され、描画時にプリセットの `(baseId, bangsId, backHairId)` が解決されます。プリセット未指定 (空文字) の場合は cut state の `baseId` だけが使われ、前髪・後ろ髪は無し扱いです。
- アセット側にデフォルト髪型がない既存プロジェクトでは、編集画面で前髪が見えなくなる場合があります。アセット管理で髪型プリセットを 1 つ作って `デフォルト` を付ければ自動補正されます。

### プロジェクト編集 UI からは触れない

髪型プリセットの追加・編集・削除は **アセット管理ダイアログ専用** です。カット編集側からは選択しかできません。配布アセットでも同じ定義が使えるよう、アセット側で完結させる設計です。

## 表情プリセット (expression preset) {#expression-presets}

頬・目・口の組み合わせを名前付きで保存する仕組みです。アセット側 (`assets/characters/<id>/expression_presets.json`) と プロジェクト側 (`projects/<project_id>/expression_presets.json`) の **2 段マージ** で動きます。

```json
[
  {
    "id": "smile",
    "name": "笑顔",
    "characterId": "default",        // プロジェクト側のみ。アセット側は省略
    "cheekId": "cheek_赤味",
    "eyeId": "eye_笑い",
    "mouthId": "mouth_あ",
    "isDefault": false
  }
]
```

### マージルール

| 状況 | 採用される値 |
| --- | --- |
| アセットだけに同 ID プリセットがある | アセット側を採用 (`origin: "asset"`) |
| プロジェクトだけに同 ID プリセットがある | プロジェクト側を採用 (`origin: "project"`) |
| 両方に同 (characterId, presetId) のプリセットがある | **プロジェクト側が優先** (override) |
| `isDefault` が両方に立っている | プロジェクト側を優先し、アセット側の `isDefault` は false 化 |

カット編集パネルの「表情プリセット」セレクタには、両者を merge した結果が表示されます。アセット由来は `(アセット)`、デフォルトは `★` 付きで表示されます。

### 編集画面での操作

- **アセット側プリセットの追加・編集**: アセット管理ダイアログから `表情プリセット` アイコンを押して開く専用ダイアログで CRUD できます。配布アセットの一部として扱われ、すべてのプロジェクトに自動で読み込まれます。
- **プロジェクト側プリセット**: 編集画面の「表情プリセット」セレクタ横の `保存` ボタンで現在のキャラ表情をプロジェクトに保存できます。アセット由来プリセットを選択した状態で組合せを変更し保存すると、**同 ID で project override が作成され**、そのプロジェクトでだけアセット定義より優先されます。アセット側のファイルは無傷のままです。
- アセット由来のプリセットは編集画面の `削除` ボタンが無効化されます。プロジェクト固有 override の削除は可能で、削除後はアセット側の定義に戻ります。

## 白背景素材を使う場合

透過 PNG が理想ですが、白背景付き素材も利用できます。
キャラクター設定 (またはカット内設定) で `白背景を透過扱いにする` を有効にすると、`#FFFFFF` 完全一致のピクセルだけを透明化します。
白い服や白い小物、ハイライトが消える可能性があるため、可能であれば事前に透過 PNG として書き出しておくのを推奨します。

## 黒線アンチエイリアス (PSD インポート時に焼き込み)

純黒 (`#FFFFFF` ではなく `#000000`) で描かれた線画キャラ向けの専用アンチエイリアス処理です。
**PSD インポート時に各レイヤー PNG へ焼き込む**形で動作します。再生時の追加コストはありません。

アルゴリズムは「黒インクをマスク化して再配置する」流れで、汎用 MLAA と違って黒線以外の色 (肌の陰影、髪の色違いなど) には作用しません。

1. 各レイヤー PNG に対し `RGB == (0,0,0) かつ alpha > 0` のピクセルを黒線マスクとして抽出
2. 黒線ピクセルの RGB を近傍の非黒不透明色で塗り潰した「下地」を作る (3×3 反復ダイレーション)
3. 黒線マスクを Gaussian blur した soft mask を作り、元から黒だったピクセルは 1.0 に preserve
4. 下地の上に黒 (0,0,0) を soft mask の alpha で premultiplied composite

結果として:

- **内部の黒線** (線 ↔ 肌・服・髪) は線が周囲色に滑らかに馴染む
- **シルエットの黒線** (線 ↔ 透明) は線芯はシャープなまま、外側に半透明黒のフリンジが出る。どの背景の上に重ねても halo が出ない
- 黒線以外 (肌の陰影や髪の色違い) は **一切変化しない**

### 使い方

PSD インポータダイアログ下部の **黒線アンチエイリアス** チェックボックスを ON にして取り込みます。
**白背景を透過** と組み合わせる場合は順序が重要で、必ず `白透過 → 黒線 AA` の順で適用されます (アンチエイリアスをかけると境界で純白が失われるため)。

### プリセット

チェックボックスを ON にすると AA プリセットセレクタが有効になり、以下から選べます。

| プリセット | `sigma` | `black_threshold` | `inpaint_max_iterations` | 特性 |
| --- | --- | --- | --- | --- |
| シャープ | 0.4 | 0 | 8 | 線芯くっきり、外側フリンジ最小 |
| **標準 (既定)** | 0.6 | 0 | 8 | バランス重視。多くの線画に最初に試す値 |
| ソフト | 1.0 | 0 | 8 | 線を周囲色によく馴染ませる |
| マイルド | 1.5 | 0 | 8 | かなり柔らかい印象 (滲み感が強くなる) |
| 太線対応 | 0.7 | 10 | 16 | 太い黒塊や圧縮ノイズの近黒も対象。標準よりやや軟調 |

絵柄や線の太さによって相性が異なるので、同じ PSD を別 ID で複数回インポートして見比べるのが手早いです。
気に入った見え方が決まらない場合や、絵柄的にそもそもアンチエイリアスをかけたくない場合は、チェックを OFF にして取り込んでください。

実装は `app/black_line_aa.py`。再処理したいキャラは PSD を再インポートしてください (素材 PNG に焼き込まれているため、後から見直したくなったときも明示的な操作になります)。
