# 素材管理

素材は、全プロジェクトで使う共通素材と、特定プロジェクトだけで使うプロジェクト固有素材に分かれます。
両方に素材がある場合、プロジェクト固有素材と共通素材があわせて選択肢に表示されます。

## 共通素材

```text
assets/
  characters/
  backgrounds/
  videos/
  audio/
  sound_effects/
  fonts/
  overlays/
```

## プロジェクト固有素材

```text
projects/<project_id>/
  assets/
    characters/
    backgrounds/
    videos/
    audio/
    sound_effects/
    fonts/
    overlays/
```

`projects/` の保存先は全体設定で別ディレクトリへ切り替えられます。

## 背景

背景は `backgrounds/` に置きます。対応拡張子は `.png` / `.jpg` / `.jpeg` / `.webp` / `.avif` です。
出力時は 1920×1080 にカバー配置されます。

## 動画背景

シーンの `videoTrack` で使う動画は `videos/` に置きます。対応コンテナは `.mp4` / `.mov` / `.webm` など、ffmpeg / ブラウザ両方が読める形式を推奨します。`fit` (cover / contain / fit)、`muted`、`loop`、`trimStartSec` / `trimEndSec`、`speed` を指定できます。

## 音声

音声は `audio/` に置きます。対応拡張子は `.wav` / `.mp3` / `.m4a` / `.aac` / `.ogg` です。
カットに音声を設定すると、口パク解析と動画書き出しの両方で利用されます。
シーンの BGM (`bgmTracks`) も同じ拡張子をサポートし、`volume` / `fadeInSec` / `fadeOutSec` / `useForLipSync` で挙動を調整します。

## 効果音

効果音は `sound_effects/` に置きます。対応拡張子は音声と同じく `.wav` / `.mp3` / `.m4a` / `.aac` / `.ogg` です。
タイムラインの効果音帯 (テロップ帯の直下) に配置すると、シーン時間軸上の任意の点で再生されます。同じ時刻に複数の効果音を重ねることができます。

スキーマは `scene.soundEffects[]` で、1 アイテムあたり次のフィールドを持ちます。

| フィールド | 用途 |
| --- | --- |
| `id` | アイテム ID (自動生成) |
| `src` | 素材ファイルパス |
| `startFrame` | 再生開始フレーム |
| `durationFrame` | 区間の長さ (フレーム数)。0 のときは素材長そのまま |
| `loop` | `true` で `durationFrame` 区間内をループ再生 (`durationFrame` が素材より長いとき) |
| `audioOffsetSec` | 素材内の頭出し秒数。タイムラインで左端をドラッグして切ったときの再生開始位置 / 「再生位置で音声分割」の右側に入る値 |
| `volume` | 音量 (0.0〜1.0+) |
| `fadeInSec` / `fadeOutSec` | 区間冒頭・末尾のフェード秒 |
| `linkedCutId` | カット境界と同期させたいときの紐付け先カット ID |

タイムライン上では効果音バーの **左右両端をドラッグでリサイズ**、**バー本体をドラッグで移動**、`Shift+クリック` で **複数選択** ができます。再生位置に乗っている効果音は「再生位置で分割」ボタンが「音声分割」に切り替わり、`durationFrame` と `audioOffsetSec` を分けて 2 つに分割します (新しい音声ファイルは作りません)。

## フォント

フォントは `fonts/` に置きます。対応拡張子は `.otf` と `.ttf` です。素材再スキャン後、書体セレクタに反映されます。
ファイル名の末尾が `Bold` / `Medium` / `Regular` などの場合は太さとして推定されます。
ライブプレビューの canvas は manifest 上のフォント情報を `FontFace` 登録して、サーバの Pillow と同じ書体で描画します。

## セリフ枠の装飾 PNG

装飾 PNG は `overlays/` に置きます。設定画面の `装飾 PNG` で選択すると、セリフ枠に重ねて描画されます。

## キャラクター

キャラクターは `characters/<character_id>/` に置きます。`character_manifest.json` がない場合でも、カテゴリフォルダ (`back_hair/` / `base/` / `cheek/` / `eye/` / `mouth/` / `bangs/` / `front/`) から素材一覧を生成できます。

```text
characters/
  sample/
    character_manifest.json
    thumb.png                  (任意)
    import_manifest.yml        (任意。配布用マニフェスト。レイヤー編集 / プリセット保存時に自動更新)
    expression_presets.json    (任意。アセット単位の表情プリセット定義)
    hairstyle_presets.json     (任意。アセット単位の髪型プリセット定義)
    back_hair/
    base/
    cheek/
    eye/
    mouth/
    bangs/
    front/
```

PSD は `characters/<character_id>/psd/` に置きます。サーバ起動時または素材再スキャン時に、未変換または更新済みの PSD を自動で再インポートします。

## 素材再スキャン

ファイルを追加・削除・差し替えた後は、ヘッダーの `素材再スキャン` を押します。
プロジェクトの `generated/manifest.json` が更新され、背景・動画・音声・フォント・装飾 PNG・キャラクターの選択肢に反映されます。

## アセット管理ダイアログ

ヘッダーの `素材` (またはダッシュボードの該当タブ) から、素材ファイルを直接管理できます。

- ドラッグ & ドロップでアップロード
- 名称変更 / 削除 / ゴミ箱からの復元 / ゴミ箱を空にする
- 共通素材 / プロジェクト固有素材の切替
- 欠落しているパス (`assetMissing`) のハイライト

### 「キャッシュ」タブ

プロジェクトツリーの **キャッシュ** を選ぶと、`projects/<id>/cache/` 配下の中間ファイル群と、全プロジェクトで共有される `cache/clean_pcm/` (録画素材の連続 PCM キャッシュ) のサイズを一覧で確認できます。

- 上段の **合計サイズサマリ** に「全プロジェクト + 共有を全削除」ボタンが付きます。
- プロジェクト別の行には `preview` (= GL バック描画の中間 PNG) と `lipsync` (= 口パク解析データ) のサイズと件数が出ます。**削除** ボタンでそのプロジェクトのキャッシュだけを空にできます。
- 一番下の **共有キャッシュ** 行で `clean_pcm` (動画レイヤーの音声 PTS gap 補正用 WAV キャッシュ) を空にできます。`psd-importer/` は PSD インポート中セッションの作業用なので、ここからは触りません (= 既存仕組みで自動管理されます)。

削除しても**プロジェクトは壊れません**。次回開いたときに必要分だけ自動再生成されます。長尺シナリオを何ヶ月も触っていると `cache/preview/` だけで数 GB に膨らみがちなので、書き出しが終わって落ち着いたら定期的に削除するのがおすすめです。

`thumbnail.png` (プロジェクト一覧用のサムネイル) は削除対象外で残ります。

### 起動時の自動間引き

`全体設定 → キャッシュ` タブで、mtime が指定日数より古いキャッシュファイルを起動時に自動削除する設定ができます。既定は **ON / 30 日**。

対象は `cache/preview/` / `cache/lipsync/` / `cache/clean_pcm/` の 3 つだけで、`thumbnail.png` と `psd-importer/` には触れません。最近編集中の token (= ファイル名 SHA1 ハッシュ) は mtime が更新されているので削除されず、起動直後のヒットレートは維持されます。

### 「音声（プロジェクト）」での未使用フィルタと一括削除

プロジェクト固有の **音声** カテゴリでは、ファイル数が増えがちな TTS 生成物 (`audio/tts/*.wav`) を効率的に整理するための専用ツールバーが表示されます。

- **未使用のみ表示** チェックで、現在のシナリオに参照されていない音声だけに絞り込めます。参照判定は `cut.audio` (話者音声) と `scene.bgmTracks[].src` (BGM) を走査して行います (効果音は別カテゴリなので対象外)。
- 各音声カードの右上に **「使用中」 / 「未使用」** バッジが付き、左上にチェックボックスが付きます。使用中の音声はチェックボックスが無効化されているので、誤って削除されません。
- **「未使用を全選択」** で表示中の未使用音声をまとめて選択 → **「選択した音声を一括削除」** でゴミ箱へ送れます (個別カードの「削除」ボタンも従来どおり使えます)。ゴミ箱からは復元できます。

このツールバーは「音声（プロジェクト）」でのみ表示されます。共通音声、効果音、その他のカテゴリには出ません。

## キャラクターサムネイル

キャラクターのサムネイルは `<character_id>/thumb.png` を優先して使用します。
PSD インポート時に `thumb` / `thumbnail` / `サムネイル` / `サムネ` のレイヤーがあれば自動で書き出されます。
手動で差し替えたい場合は同名の PNG を直接配置してください。

## レイヤー編集 (目パチ・口パクのフラグ + 表示名)

`キャラ管理` ダイアログから `レイヤー編集` を開くと、各レイヤーに以下を設定できます。

- **表示名 (`name`)**: セレクタやリストで使われる人間向けラベル。インポート直後の機械生成名 (例: `制服_デフォルト`) を読みやすい名前に直したい場面に。レイヤー ID は不変なので、シナリオの参照は壊れません。
- **目パチフラグ (eye)**: `開き` (= `blinkOpen`) / `中間` (= `blinkHalf`) / `閉じ` (= `blinkClosed`)
- **口パクフラグ (mouth)**: `閉じ` (= `lipClosed`) / `中間` (= `lipMid`) / `開き` (= `lipOpen`)

`blinkOpen` 以外は manifest 全体で **1 枚だけ** 立てられる排他フラグで、別レイヤーで ON にすると自動で外れます。フラグの動作詳細は [キャラクターモデル](../technical/character-model.md#blink-lipsync-flags) を参照してください。

設定した表示名 / フラグは `character_manifest.json` の各エントリに書き込まれ、`import_manifest.yml` の `flags:` ブロックや `expressionPresets` / `hairstylePresets` 内のレイヤー名参照も同期更新されます。

## 表情プリセット / 髪型プリセット (アセット定義)

ダッシュボード → アセット管理から各キャラクターカードに 2 つのプリセット編集アイコンが追加されています。

- :material-emoticon-outline: **表情プリセット**: 頬 + 目 + 口 の組合せをアセット側で名前付き保存します。プロジェクト編集画面のセレクタにも `(アセット)` 印つきで自動表示されます。プロジェクト固有の組合せ上書きはカット編集の「保存」ボタンで作れます ([詳細](../technical/character-model.md#expression-presets))。
- :material-content-cut: **髪型プリセット**: ベース + 前髪 + 後ろ髪 の組合せを名前付き保存します。アセット定義のみで完結し、プロジェクト固有の上書きは持ちません。`デフォルト` を 1 つ立てておくと、新規キャラ追加時に自動選択されます ([詳細](../technical/character-model.md#hairstyle-presets))。

どちらのプリセットも `assets/characters/<id>/expression_presets.json` / `hairstyle_presets.json` に保存され、保存と同時に `import_manifest.yml` も透過ミラーで再生成されます。配布用アセット ZIP にそのまま同梱できます。

## キャラクターカラー

ヘッダーの `キャラ管理` でキャラクターを選んで開くダイアログ右上に、**カラー** ピッカーがあります。ここで設定した色 (`character_manifest.json` の `color` フィールド) は次の場所で表示色に反映されます。

- 編集画面の **アクティブなカットカード** のアクセントカラー（タイトル左の縦バー / 枠線 / 背景塗り）
- タイムライン下部の **カットバー** の塗り色

「未指定」（`color` 空文字）のときは従来どおりテーマのアクセントカラーが使われます。話者キャラが未設定のカット、もしくは話者キャラの色が未指定のカットも未指定扱いです。色を再設定したいときは、ピッカーの右の `restart_alt` ボタン（「未指定（アクセントカラーを使う）に戻す」）を押すと初期化できます。
