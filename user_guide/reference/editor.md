# 編集画面リファレンス

編集画面は、上部ヘッダー / ライブプレビュー / 右パネル / 下部タイムラインで構成されています。

## 上部ヘッダー

| 操作 | 説明 |
| --- | --- |
| プロジェクト名 | クリックするとプロジェクト一覧 / 切替メニューが開く |
| ダッシュボード | プロジェクト全体の管理画面に戻る |
| 素材再スキャン | 背景・音声・装飾 PNG・フォント・キャラクター素材を再読み込み |
| キャラ管理 | キャラクター定義の編集・インポート・削除 |
| PSD インポート | PSD アップロード → ツリー確認 → 取り込み |
| PNG 出力 | 選択中カットを PNG として保存 |
| MP4 出力 | シナリオ全体を動画として保存 (書き出しダイアログを開く) |
| 設定 | プロジェクト設定 (文字 / セリフ枠 / 動画 / 口パク解析) |
| 全体設定 | アプリ全体の設定 (ffmpeg / プロジェクトフォルダ / 動画プリセット / Undo 履歴 / quietMode / バックアップ / キャッシュ自動間引き) |
| テーマ | ライト / ダーク切替。`prefers-color-scheme` で初期化、`localStorage` に永続化 |

## ライブプレビュー

中央のライブプレビューには、選択中フレームの合成結果が表示されます。

- `再生` / `停止`: 再生ヘッドの位置からシーン末尾まで通し再生。Space キーでも切り替え可。
- 波形 + dB メーター: セリフ音声と BGM のミックス。口パク解析の入力を視覚化。
- 動画背景 (`videoTrack`) があるシーンでは WebGL シーンに `VideoTexture` として取り込まれ、キャラ・セリフ・テロップ・ビジュアライザが同じ GL canvas 上で合成される。
- 再生ヘッド位置はプロジェクトに保存され、再起動後にカット位置から復元される。

### キャラのドラッグ&ドロップ配置

停止中のプレビュー上でキャラクターを **直接ドラッグして配置** できます (`キャラ配置` タブを開いているとき)。

- キャラをクリックすると、右パネルの「登場キャラ」セレクタも自動でそのキャラに切り替わります。
- ドラッグ中は X / Y 入力もリアルタイムで追従し、ドロップしたタイミングで `updateSelectedCutFromCurrent` + 自動保存 + Undo 履歴が走ります。
- キャラが重なっている場合は、見た目で **前面のキャラを優先** してつかみます。
- 再生中はドラッグ操作を受け付けません (誤操作防止)。

ライブプレビュー / 静止 still render は GL canvas で直接描画され、キャラレイヤー PNG (`projects/<project_id>/cache/preview/`) は state hash でファイル名が固定なので、設定が変わらなければ再生成されません。

### トランスポートバー（再生ボタン周り）

再生ボタンの両脇には、再生ヘッドを動かすボタンとループトグルが並びます。

| ボタン | 動作 |
| --- | --- |
| :material-page-first: 先頭へ | 再生ヘッドをシナリオ先頭 (0 秒) に移動 |
| :material-chevron-double-left: 1 秒戻す | 再生ヘッドを 1 秒 (= プロジェクト FPS 分のフレーム) 戻す |
| :material-chevron-left: 1 フレーム戻す | 再生ヘッドを 1 フレーム戻す |
| :material-play: 再生 / 停止 | 再生開始 / 停止トグル |
| :material-chevron-right: 1 フレーム進める | 再生ヘッドを 1 フレーム進める |
| :material-chevron-double-right: 1 秒進める | 再生ヘッドを 1 秒進める |
| :material-page-last: 終端へ | 再生ヘッドをシナリオ終端 (= 末尾カット末尾 / テロップ末尾の最大) に移動 |
| :material-repeat: ループトグル | クリックで「なし → カット内 → シーン全体」を循環。:material-repeat: (なし / シーン) と :material-repeat-once: (カット) でアイコンが変わり、有効時はアクセントカラーで表示 |

:material-page-first: :material-chevron-double-left: :material-chevron-double-right: :material-page-last: のどれを使っても、ジャンプ先がいま編集中のカットと違うときは自動で右パネルにそのカットが読み込まれます（`Home` / `End` キーも同じ挙動になりました）。

### ループ再生モード

再生開始後、シナリオ末尾まで来たときの挙動はループトグルで切り替えます。

| モード | 動作 |
| --- | --- |
| なし (`off`) | 末尾まで再生したら停止（従来挙動）|
| カット内 (`cut`) | 1 カット再生し終わるたびに、そのカット先頭へ戻って繰り返す |
| シーン全体 (`scene`) | シナリオ通し再生し終わるたびに、先頭カットへ戻って繰り返す |

ループ境界では BGM と音声が一旦止まって即座に再起動します（再生ヘッドの基準を取り直すため）。`R` キーでもトグルできます。

## 右パネル: 編集タブ

右パネルは選択中アイテム (カット or テロップ) の種別に応じて中身が差し替わります。テロップが選択されているときはテロップ用の編集 UI、それ以外はカット用の `キャラ配置` / `お芝居` / `演出` の 3 タブが表示されます。

### キャラ配置タブ

| 項目 | 説明 |
| --- | --- |
| 登場キャラ | カット内で編集中のキャラを選ぶ。ラベル横にカット内インスタンス ID (`character_XXXX_n`) が表示され、クリックでクリップボードへコピーできる (セリフ書き出し YAML の `speaker` 値と突合できる) |
| 前へ / 後ろへ | カット内のキャラ描画順を変更 |
| 削除 | カットから選択中キャラを外す (素材自体は残る) |
| 追加 | `素材キャラ` で選んだキャラをカットに追加。セレクタの表示は「表示名（CID: id / 共通 or プロジェクト / READ ONLY）」形式で、同じ表示名でも別キャラ ID なら CID で区別できる |
| 置換元 / 置換先 | 「キャラ素材を置き換え」用のセレクタ。`素材キャラ` と同じ CID 付き表記 |
| X / Y | 配置座標 (プレビュー上の直接ドラッグでも変更可) |
| 拡大率 | 表示倍率 |
| 左右反転 | キャラ本体レイヤー (ベース・前髪・後ろ髪・目・口・前面) のみを中心軸で左右反転する。光彩・ドロップシャドウは固定の向きを保ったまま反転後のシルエットから生成される。`scale` を負数化する方式とは異なるため、X/Y 計算や中央寄せロジックを壊さない |
| 白背景を透過扱いにする | キャラ単位設定。runtime で `#FFFFFF` を α=0 に置き換える。PSD インポート時に「白背景を透過」チェックを ON にして素材へ焼き込んであるキャラはここを OFF にしても結果は変わらない |
| 左右中央 / 初期位置 / 同一キャラに一括適用 | 中央寄せ / 既定値へ復帰 / 他カットの同 `characterId` キャラへ X/Y/拡大率/白背景 をチェック式で一括反映 |
| 体 / 頬 / 目 / 口 / 髪型 / 前面 | キャラ素材を選ぶ。前面 (`front/`) は複数同時表示可。「髪型」はアセット定義のプリセット (ベース+前髪+後ろ髪) を 1 個のセレクタで選ぶ ([詳細](../technical/character-model.md#hairstyle-presets))。髪型セレクタの右に「目を前髪より前に出す」チェックボックスが並ぶ |
| eyeAboveBangs | 目を前髪より前に重ねる (カット単位フラグ) |
| 表情プリセット | 頬 + 目 + 口 の組み合わせを呼出し / 保存 / 削除。アセット由来は `(アセット)` 表示・削除不可、デフォルトは `★` 付き ([詳細](../technical/character-model.md#expression-presets)) |
| キャラクターを表示 | このキャラを表示するかどうか |

### お芝居タブ

カット 1 つに紐付くセリフ・音声をまとめて編集します。順序: 音声 + 秒数 → 話者 → 声 / 感情 / 音声を再生成 → 本文 → 文字スタイル → セリフ文字エフェクト → 文字設定を一括反映 / 同一話者に一括反映 → 文字枠スタイル → トグル → 文字枠を一括設定。背景・モーション・キャラクター効果は隣の `演出` タブに移動しています。

| 項目 | 説明 |
| --- | --- |
| 音声 | カットで再生する音声素材を選ぶ |
| 秒数 (フレーム) | カットの表示フレーム数。1 frame 単位 |
| 話者 | セリフを話しているキャラを選ぶ。紐付け済みなら下の「声」「感情」が自動同期 |
| 声 / 感情 | VOICEVOX / VOICEPEAK で音声合成するときの声と感情 (VOICEPEAK のみ感情有効)。話者と独立に上書き可 |
| 音声を再生成 | 上記の声 / 感情 + 本文で wav を再合成し、カットの音声と表示時間を更新する |
| セリフ本文 | 表示するテキスト (改行可)。日本語の禁則処理に対応しており、行頭に句読点 (`、 。`) や閉じ括弧 (`） 」`) が来そうなときは前行末にぶら下げ、行末に開き括弧 (`（ 「`) が来そうなときは次行頭へ送ります |
| 文字サイズ / 書体 / 太さ / 文字揃え / 行数 | テキストスタイル。文字揃えは `左揃え` / `中央揃え` |
| 帯の濃さ / テキスト色 / アウトライン色 / アウトライン幅 | セリフ枠とテキスト装飾 |
| セリフ文字に光彩 | セリフ本文 (文字) の外側にぼかし発光を載せる (`色` + `ぼかし` + `強度`)。プロジェクト設定の `dialogueGlow` 既定値を上書きするカット単位設定 |
| セリフ文字にドロップシャドウ | セリフ本文 (文字) の下に影を落とす (`色` + `ぼかし` + `強度` + `X 方向` / `Y 方向` オフセット)。プロジェクト設定の `dialogueDropShadow` 既定値を上書きするカット単位設定 |
| 文字設定を一括反映 | 現在のカットの「文字サイズ / 書体 / 太さ / 文字色 / アウトライン / アウトライン色 / 文字揃え / 文字間 / セリフ光彩 / セリフドロップシャドウ」を、他カットへチェック式で一括反映 |
| 同一話者に文字設定を一括反映 | 上記と同じ反映ダイアログを、**現在のカットの話者と同じ `characterId` を持つカットだけ** に適用する。セリフ枠 (枠位置 / 行数 / 帯の濃さ等) は対象外 |
| 枠位置 | `top` / `bottom` / `left` / `right` / `center` |
| セリフ枠を表示 / 話者名を表示 / キャラクターを表示 | 表示トグル |
| 文字枠を一括設定 | 「枠位置 / 行間 / 行数 / セリフ枠 / 話者名」を他カットへ一括反映 |

#### セリフ枠のブレンドモード

セリフ枠の **背景色** と **ボーダー色** は、それぞれの明度から自動でブレンドモードが決まります。

| 色の明度 | ブレンドモード | 効果 |
| --- | --- | --- |
| 明るめ (luminance > 0.5) | スクリーン | 背景色を「足して飽和させる」方向に合成。白に近い枠が背景に浮かびつつ抜ける |
| 暗め (luminance ≤ 0.5) | 乗算 | 背景色を「掛けて暗くする」方向に合成。黒に近い枠が背景の色味を残したまま落ち着く |

`帯の濃さ (boxOpacity)` を `0` にすると背景・ボーダーともに完全透明 (= 何も合成しない) になります。ボーダーの不透明度は `boxOpacity` に連動するため、「濃さ 0」で枠全体がきれいに消えます。文字 (本文 / 話者名) / 装飾 PNG は従来どおり通常合成です。

「声」「感情」「音声を再生成」は VOICEVOX / VOICEPEAK のどちらも検出されていないときは無効化されます。詳細は [音声合成 (VOICEVOX / VOICEPEAK) を使う](../tutorials/voice-synthesis.md) を参照。

### 演出タブ

カット単位の「背景・場面」と「キャラクター効果」をまとめて編集します。

#### 背景・場面

| 項目 | 説明 |
| --- | --- |
| モーション | 横シェイク / 縦シェイク / 拡大 (カット単位の単純変位) |
| 背景 | カットの静止画背景を選ぶ (`videoTrack` がない場合に使用)。新規プロジェクトの既定値は **なし（透過）**。プロジェクトに登録済みの背景画像がある場合でも、明示的に選ぶまでは透過のまま |
| 背景ぼかし (px) | 背景に Gaussian blur を掛ける (0 で無効) |
| 背景色 / 背景色 不透明度 | 背景画像が未指定のときに表示される単色塗りつぶし。既定は完全透明 (`opacity = 0`)。背景画像 / 動画背景を指定するとそちらが優先される |
| 前景 | キャラの上に重ねる装飾（`foregrounds/` から選択） |
| 背景・場面を一括適用 | 上記項目を、チェックを入れた項目だけ他カットへ一括反映（背景色と不透明度はペアで反映） |

#### キャラクター

このカットに登場するキャラクター全員に対する追加エフェクトです。3 種は独立に ON / OFF できます。

| 項目 | 説明 |
| --- | --- |
| 色フィルター（乗算）| 指定色を乗算合成 (`color` + `opacity`) |
| 光彩 | 外光彩 (`color` + `blurPx` + `opacity`) |
| ドロップシャドウ | 影 (`color` + `blurPx` + `opacity` + `X 方向` / `Y 方向` オフセット) |
| キャラクター効果を一括適用 | 上記 3 ブロックを「有効/無効・色・強度・オフセット」ごと丸ごと、チェックを入れたブロック単位で他カットへ反映 |

#### ビジュアライザ

シーンに 1 つ重ねられる装飾レイヤです。`演出` タブの「ビジュアライザ追加」から選択でき、レイヤ位置 (背景の上 / キャラの上 / 前景の上) も切り替えできます。組み込みプリセットの代表例:

| プリセット | 用途 | 音/BPM 連動 |
| --- | --- | --- |
| `バー・スペクトラム` | 横並びの細いバーで音量スペクトルを可視化 (汎用版) | 音 ✓ |
| `オーディオ波形` | 中央線 + 振幅で生波形 | 音 ✓ |
| `サークルスペクトログラム` | 円周バーで FFT を可視化 | 音 ✓ |
| `ウェーブ・リボン` | 大きなソフト波線が音で揺れる | 音 ✓ |
| `ふわふわパーティクル` | 浮遊粒子が kick で拍動・onset で弾ける | 音 ✓ |
| `ジオメトリック・パーティクル` | 点群 + 直線ネットワーク | 音 ✓ |
| `カウントダウン` | シーン残時間の数字表示 (フォント / 色設定可) | — |
| `ぼかし円とグラデーション` | 2 色グラデ背景 + ふんわり浮遊する大きなボケ円 + 小さな星粒 | — |
| `降りそそぐパーティクル (星屑 / 雪 / 雨)` | 星屑 / 雪 / 雨 を選んで一定方向に降る (上下方向選択 + 傾き角度可) | — |
| `LED グリッド` | LED スクリーンを拡大したような光るドットマトリクス。色・角丸・ボケ量・点灯セル率を調整可 | **BPM ✓** (シーンの「基本」タブの BPM を使用、プラグイン側で上書きも可) |
| `光る図形 (角丸四角 / 円 / 三角 / 星)` | ネオン輪郭の図形が一定方向に流れる。背景に水玉 / 格子 / 横線 / 縦線 を置く設定も同梱 | — |
| `ウェーブリボン (ジオメトリック背景)` | 半透明の斜めリボンがゆっくり波打つ「光のサテン」風背景 | — |

各プリセットには色・サイズ・速度・角度・乱数シード等の調整パラメータが付いており、シーンに乗せた後で右パネルから即座に変更できます。新しいプリセットを書きたい開発者向けの情報は `technical/visualizer-plugin.md` を参照してください。

### テロップ編集パネル

タイムラインのテロップ帯でテロップを選択すると、右パネルがテロップ用に切り替わります。

| 項目 | 説明 |
| --- | --- |
| 開始 / 終了 / 長さ | フレーム単位で編集 |
| 位置 | `上` / `中央` / `下` / `座標指定`。`座標指定` を選ぶと直下に X / Y 入力欄が表示される |
| 本文 | テロップ文字列 (改行可) |
| 書体 / 太さ / サイズ | フォント設定 |
| 文字色 / アウトライン色 / アウトライン幅 | スタイル |
| 文字揃え / 文字間 (1/1000em) / 行間 (px) | 同じ段に 3 列で並ぶ。文字揃えは `左揃え` / `中央` / `右揃え` |
| 光彩 / ドロップシャドウ | 各カードで `有効化` トグル + 色 / ぼかし / 強度 / オフセットを編集。常時展開 (アコーディオンなし) |
| 一括追加 | 区切り文字 (改行 / 句読点) で複数テロップを一気に作成 |
| 既定値に保存 / すべてのテロップに反映 | プロジェクトの `telopDefaults` と一括スタイル反映 |

#### 登場 / 退場 / 持続モーション (通常テロップ・MV 文字 共通)

テロップ編集パネル下部に「登場アニメ」「退場アニメ」「持続モーション」「描画レイヤー」のセクションがあります。これらは **通常テロップ・MV 文字どちらでも有効** です。

- **登場アニメ** プリセット: `フェード (透明度のみ)` / `フェードスライド` / `タイプライター` / `pop_per_char` 等
- **退場アニメ** プリセット: `フェード (透明度のみ)` / `フェードスライド` 等
- **フェード (透明度のみ)** は位置を一切動かさず alpha のみ補間します。スライドさせたくない控えめなテロップに向いています。

#### MV 文字 + 視覚エフェクト (グループ・最下段)

最下段の「MV 文字 / 視覚エフェクト」グループは **MV 文字モード時のみ反映** されます。上の登場/退場/持続モーション/描画レイヤーが Caption でも効くのに対し、視覚エフェクト (`neon_glow` / `rgb_shift` / `glitch_scan` 等) は MV 文字専用です。

| 項目 | 説明 |
| --- | --- |
| MV 文字に変換 / Caption に戻す | テロップ種別を切り替える。MV に切り替えると視覚エフェクトの選択が有効化される。Caption に戻すと `effectPreset` / `effectParams` は無効化される |
| 視覚エフェクト プリセット | `neon_glow` / `rgb_shift` / `glitch_scan` 等。Caption 状態では disabled |

### 効果音編集パネル

タイムラインの効果音帯 (テロップ帯のすぐ下) で効果音を選択すると、右パネルが効果音用に切り替わります。スキーマは `scene.soundEffects[]` で、`{ id, src, startFrame, volume }` のみを持つ最小構成です。

| 項目 | 説明 |
| --- | --- |
| 効果音アセット | アセット管理の「効果音」カテゴリに登録した素材から選択 |
| 開始時間 | フレーム単位 (MM:SS.FF) で編集。配置はマウスドラッグでもタイムライン上で変更可 |
| 音量 | 0.0–2.0 (BGM トラックと同じレンジ) |

長さ (`durationFrame` 相当) はアセットの長さがそのまま使われるため編集できません。タイムライン上ではアセットの長さに応じたチップ幅で表示されます (取得済みのものから順に幅が確定)。フェードイン / アウトはサポートしていません。シーン頭から `startFrame` の時刻に到達した瞬間に再生し、自然に終了します。

同じ時刻に複数の効果音を重ねて配置することもできます。`scene.soundEffects[]` は scene 単位の配列なので、カットを複製しても効果音は付随しません。

### 動画レイヤー編集パネル

タイムライン最下段の動画レイヤー帯で動画レイヤーを選択すると、右パネルが動画レイヤー用に切り替わります。背景動画 (`videoTrack`) と違い、シーン中の任意区間に置けて、フェードイン / フェードアウトや配置位置・拡縮を指定できる短いクリップ向けのレイヤーです (タイトル動画、トランジション、解説動画など)。スキーマは `scene.videoLayers[]` です。

| 項目 | 説明 |
| --- | --- |
| 動画アセット | アセット管理の「動画」カテゴリに登録した素材から選択 |
| 開始時間 | シーン頭からの配置位置 (MM:SS.FF) |
| 素材内 開始秒 / 終了秒 | trim 範囲。タイムライン上の長さはこの差分から派生 (`durationFrame` は持たない) |
| アスペクト処理 (fit) | `contain` (内接 / 余白あり) / `cover` (全面 / クロップ) / `fill` (引き伸ばし) |
| 縮尺率 | fit 適用後の追加倍率 (縦横比維持、0.05〜4.0) |
| 位置 X / Y | 中央アンカーからのピクセルオフセット (+X=右、+Y=下、±2000) |
| レイヤー (z 位置) | `前景の上` (キャラ・前景イラストの手前) または `背景の上` (キャラの後ろ) の 2 択 |
| 不透明度 | 0.0–1.0 (フェードを掛ける前のベース) |
| フェードイン / フェードアウト | チェックボックスで有効化、秒数を独立指定 (開始だけ / 終了だけも可)。**映像 (alpha) と音声 (volume) の両方** に同じカーブで掛かるので、音声側は別途指定する必要はありません |
| 音声をミュート / 音量 | 動画に音声トラックがあれば書き出しの amix に合流。音声無しの動画は自動でスキップ |

タイムライン上の操作も SE と同じく `Shift+D` で複製・`Backspace` で削除・`↑`/`↓` で隣接選択ができます。同一 `レイヤー` (BG / FG) 内でも **時間軸の重なりは許容**（クロスフェード用途で意図的に重ねられます）。同 layer 内で重なったときの z 順は **配列順**（後ろの要素ほど手前）で、編集パネル右の **「重なり順」前へ / 後ろへ ボタン** で入れ替えます。異なる `レイヤー` を組み合わせれば「背景の上で映像が流れている裏でキャラの前にトランジション動画」のような重ね合わせも可能です。

書き出しでは映像はそのまま GL に焼かれ、音声は ffmpeg amix で BGM / 効果音と合流します。フェード / 不透明度は GL plane の alpha に毎フレーム反映されます。

#### 録画素材を取り込むときの再エンコードチェック

NVIDIA ShadowPlay などのゲーム録画ツールで作られた MP4 は、フレームドロップ箇所で **PTS (Presentation Timestamp) が飛ぶ** ことがあります（映像トラックの名目尺と実際の音声サンプル数がずれる）。このまま動画レイヤーに使うと、プレビュー中盤以降の音ズレや、書き出し時の `apad` / `atrim` のはみ出しといった症状が出ます。

立ち絵システムは動画レイヤーで素材を選択した直後・動画レイヤー追加直後に **PTS gap の検査** を自動で走らせます (`/api/video/probe-gaps`)。合計 gap が 50 ms を越えたとき、再エンコード推奨ダイアログが開きます。

ダイアログには、

- **名目尺 / 実音長** (= 映像トラックが申告する duration と、実際の音声サンプル数から求めた duration)
- **検出された gap の箇所数 / 合計秒数**
- **エンコーダ プリセット** (HW / balanced / quality)

が表示されます。HW プリセットは検出された専用回路がある環境でのみ表示され、既定で選択されます（macOS=VideoToolbox / NVIDIA=NVENC / Intel iGPU=QSV / Linux=VA-API）。

`再エンコードする` を押すと進捗ダイアログに切り替わり、`ffmpeg -vsync cfr` + `aresample=async=1000` で **同一フォルダに `<元ファイル名>.fixed.mp4`** と sidecar の `<元ファイル名>.fixed.mp4.json` が出力され、動画レイヤーの参照先が自動で `.fixed.mp4` に切り替わります。元ファイルは残るので、再度開いたときは sidecar の SHA を見て「すでに修正済み」と判定し、ダイアログは出ません。

- `キャンセル` を選んだ場合は元ファイルのままレイヤーに取り込みますが、上記の症状が出る可能性があります。
- 再エンコードは GPU エンコーダがあれば実時間より高速、ソフトウェア (libx264) でも 1080p 60fps 程度なら実時間の数倍速で済みます。
- gap が無い（または極小の）素材ではダイアログ自体が開かないため、通常運用では特に意識する必要はありません。

## タイムライン

下部のタイムラインは ruler / 波形 / テロップ / 効果音 / 動画レイヤー / カットを 1 枚の canvas に描画します。シーン切替プルダウンで対象シーンを切り替えます。

- カットを選ぶと、そのカットの状態が右パネルに読み込まれます。
- 末尾の追加カードから新しいカットを挿入できます (現在のカットを複製して `index+1` 位置に挿入)。
- ruler (時間軸) クリックで再生ヘッドが移動し、その位置のカットが自動で右パネルに読み込まれます。
- ズームボタンで横スケールを変更可能。`#timelineSpacer` + sticky canvas で長尺でも寸法上限に当たりません。
- BGM トラックは波形入りで表示され、選択中のトラック / 口パク用トラック (`useForLipSync`) を強調表示。

### 磁力スナップ

タイムライン上のテロップ / 効果音 / 動画レイヤーをドラッグして移動・端をリサイズするとき、近くの境界に **自動で吸い付く** ようになっています。優先度が高い方が勝つので、複数候補が重なっていても自然に揃います。

| 優先度 | スナップ先 |
| --- | --- |
| 1 | 再生ヘッド (playhead) |
| 2 | カット境界 (各カットの先頭・末尾フレーム) |
| 3 | BPM 拍 (シーン設定で BPM 指定時) |
| 4 | 他のテロップ / 効果音 / 動画レイヤーの先頭・末尾 (自身および同時ドラッグ中のグループ全員は除外) |
| 5 | フレームグリッド (1/24 秒) |

ドラッグ中、スナップが効いた瞬間に **アクセントカラーの薄い破線** が縦に立って「ここに揃いました」を可視化します。

- スナップを一時的に切るには **`Shift` を押しながらドラッグ**
- 微調整は **右パネルの数値入力（タイムコード）** または **`←` / `→`（1 frame）** / **`Alt`+`←`/`→`（1 秒）** ショートカット
- カット境界を含む全アイテム間で吸い付くため、場面転換テロップとカット先頭の位置合わせも狙いやすくなっています。

### シーン設定ダイアログの BGM タブ

シーンの **BGM** タブから「BGM を追加」で複数の音源トラックを並べられます。各トラックでは以下を編集できます。

| 項目 | 説明 |
| --- | --- |
| ソース | 音源アセット (アセット管理の「音声」カテゴリから選択) |
| 音量 (0〜2) | 出力ボリューム |
| トリム開始 | 素材内のどの位置から鳴らし始めるか (秒) |
| フェードイン / フェードアウト | 秒数。シーン頭・終端での音量カーブ |
| このトラックをループする | ON のとき、シーン終端まで素材を繰り返し再生する。**排他ではない** ので、複数のトラックを同時にループに設定できる。プレビュー / 書き出し どちらも同じように繰り返される |
| このトラックを口パク入力に使う | シーン内 1 トラックのみ ON 可能 (ラジオ式)。`useForLipSync = true` のトラックは出力ミックスから外され、口パクメーター・口パク振幅判定の入力源として使われる |

### カットカードの表示

カットリスト (timeline 上部の横スクロール) のカードは:

- **タイトル行**: そのカットのセリフ本文
- **メタ行**: 話者キャラ名 / 音声ファイル名（タイムコードはホバー tooltip）

カード幅はセリフの長さによらず固定です（タイトルは長文だと末尾が `…` で省略表示されます）。

active なカットのアクセントカラーには、話者キャラに設定された **キャラクターカラー** が使われます（タイムライン下部のカットバーも同じ色、`Shift+クリック` などの範囲選択中カードも同じ色で薄く光ります）。話者なし or キャラクターカラー未指定なら従来どおり既定のアクセントカラー。色はキャラ管理ダイアログで設定します。

### カット一覧のスクロールと自動追従

カットリスト (timeline 上部) は次の挙動になります。

| 操作 | 動作 |
| --- | --- |
| マウスホイール (縦) | カットリスト上にカーソルがあるときは、縦ホイールが横スクロールに変換されます。ease-out で減衰する慣性付きで、ぎこちなく飛ばない程度の速さに調整しています |
| `Shift` + ホイール / トラックパッド 2 本指水平スワイプ / スクロールバー直ドラッグ | 従来どおりブラウザ純正の横スクロール（こちらが効いているときは縦ホイール変換は無効化） |
| 再生中 | 再生ヘッドが乗っているカードが視界外に出ると、なめらかにスクロールして引き込みます（タイムラインの自動追従と同じタイミング） |
| シーク (先頭へ / 終端へ、`Home` / `End`、ruler クリック、フレーム移動ショートカット 等) | 再生ヘッドの移動先カードが視界外なら、同じくスクロールで引き込みます |

### カットカードのクリック動作

| 操作 | 動作 |
| --- | --- |
| シングルクリック | カードを選択して右パネルに読み込む（従来通り） |
| ダブルクリック | 再生ヘッドをそのカットの先頭フレームへ移動する。シングルクリックの選択動作も同時に走るが、副作用は薄い |
| `Shift` + クリック | アンカー（直前の単一選択）から連続範囲を選択 |

### タイムライン上部のクイックボタン

シーン設定の右隣にカット操作ボタンが並びます。

| ボタン | 動作 |
| --- | --- |
| **カットへリンク / リンク解除** (トグル) | 選択中のテロップ / 効果音 / 動画レイヤーを、cut-list で active 表示中のカット（無ければ再生ヘッドを含むカット）へ紐付ける / 紐付け解除する。選択 0 件のときは無効。選択中に未リンクが 1 件でもあれば「カットへリンク」表示で全件リンク、すべてリンク済みなら「リンク解除」表示で一括解除（=トグル）。詳細は [カットへのリンク](#カットへのリンク) を参照 |
| 選択カットを複製 / 選択テロップを複製 / 選択効果音を複製 | 選択中の種別 (カット / テロップ / 効果音) に応じてラベルが切り替わり、`Shift+D` と同じ動作になる |
| 選択カットを削除 / 選択テロップを削除 / 選択効果音を削除 | 同上で `Backspace` と同じ動作。Undo で復帰可 |
| 再生位置で分割 (ハサミ) | 再生位置を含むカットを 2 つに分割。前半は元のセリフ・音声を保持、後半は視覚状態 (キャラ配置・背景・効果) を引き継いだうえで音声とセリフ本文をクリアする。境界線上 (frame=0 / 終端) では何もしない |
| 再生位置にカット終端 (ものさし) | 再生位置を含むカットの終端 (`durationFrame`) を再生位置まで縮める / 延ばす |
| カットを一括追加 | 音声ファイル群から複数カットをまとめて作成 |
| テロップを追加 / テロップ一括追加 | テロップ単発追加 / 複数まとめて追加 |
| 効果音を追加 | 再生ヘッド位置に効果音 1 件を追加。アセット選択は右パネル側で行う |
| アイテムを追加 → タイトル | 別ページの [タイトル組版エディタ](title-editor.md) を開く。本編とは独立した PNG (透過可) を作って前景アセットとして取り込める。遷移前に現在のシナリオは自動保存される |

### カットの選択・並び替え・複製・削除

複数カットを選んでまとめて操作できます。

| 操作 | 動作 |
| --- | --- |
| クリック | 単一選択 |
| `Shift` + クリック | アンカー（直前の単一選択カット）から連続範囲を選択 |
| `Shift` + `←` / `→` | 単一選択を左右に広げて連続範囲選択 |
| `Alt` (Win) / `Option` (Mac) + `←` / `→` | 選択中のカット群を前後に入れ替え |
| マウスドラッグ | 選択中のカット群を任意位置にドロップして並び替え |
| `Shift+D` | 選択中のカット（または選択中のテロップ）を複製 |
| `Backspace` | 選択中のカット（または選択中のテロップ）を削除（Undo で復帰可） |

カードのドロップ位置は左/右半分のホバーで決まり、青いラインがガイドとして表示されます。

### タイムラインアイテムの選択

タイムライン canvas 上のテロップ・効果音・動画レイヤーを選ぶときの操作です。

| 操作 | 動作 |
| --- | --- |
| クリック | 単一選択（種別は editorTarget に切替、右パネルが該当種別の編集 UI に） |
| `Shift` + クリック | 同種別の中で連続範囲を選択 |
| **`Cmd` (Mac) / `Ctrl` (Win) + クリック** | **種別をまたいで** 追加 / 解除（テロップ + 効果音 + 動画レイヤーをまとめて選んで「カットへリンク」したいときに使う）|
| 空き領域からドラッグ | マーキー（矩形範囲）選択 |
| `Shift+D` | 選択中のアイテムを複製（種別ごとに専用ロジック） |
| `Backspace` | 選択中のアイテムを削除（Undo で復帰可） |

cross-type 選択中は **3 種別すべてのバーが同時にハイライト** 表示になります（通常は editorTarget の種別のみハイライト）。右パネルは最後にクリックした種別を表示しますが、`カットへリンク` ボタンなどクロスタイプ操作はすべての選択を対象にします。

### カットへのリンク

「カットへリンク」を使うと、**テロップ / 効果音 / 動画レイヤー** をカットに紐付けて、カット操作と連動させられます。場面転換テロップ + シーン切替効果音 + ブリッジ動画みたいなセットを「1 カットの付属物」として扱いたい場面で使います。

| カット操作 | リンク済みアイテムの挙動 |
| --- | --- |
| カット並び替え (`Alt+←/→`、ドラッグ) | リンク先カットの新 startFrame に合わせて平行移動。後続カットに紐付くアイテムも、後続カットの新位置に合わせて自動シフト |
| カット複製 (`Shift+D` / 複製ボタン) | リンク済みアイテムも複製され、新カット側に同じオフセットで紐付く（元カット側のアイテムはそのまま残る）|
| カット削除 (`Backspace` / 削除ボタン) | 件数を出した確認ダイアログ → 一緒に削除（Undo で 1 ステップで戻る）|
| カット duration 変更 | リンク先カット内のアイテムはオフセットを保ったまま（手動で動かさない限り維持）。後続カット紐付きアイテムは Δdur 分シフト |

#### リンクの貼り方 / 解除

1. リンクしたいアイテムを選ぶ（`Cmd/Ctrl` クリックで複数種別の同時選択も可）。
2. cut-list 上で対象カットを選ぶ（カードがアクセント色で光っている状態。再生ヘッドの位置にあるカットでも OK）。
3. ツールバーの **「カットへリンク」** ボタンを押す。トースト「N 件をカット『…』へリンクしました」が出ます。
4. ボタンが **「リンク解除」** 表示に切り替わる → もう一度押すと現在の選択のリンクを一括解除。

混在状態（一部リンク済み + 一部未リンク）のときは「カットへリンク」が表示され、押すと全部リンクされて揃います。続けてもう一度押せば全解除に揃います。

#### 可視化

リンク済みのテロップ / 効果音 / 動画レイヤーは、タイムライン上のバー **右上に鎖アイコン** が出ます。アイコン背景はリンク先カットのキャラクターカラー（speaker color）と同じなので、どのカットに紐付いているかは色で判別できます。

#### 注意点

- リンク対象アイテムを手動でドラッグして「リンク先カットの範囲外」に動かしても、**リンクは維持** されます（オフセットが更新されるだけ）。明示的に「リンク解除」ボタンを押さない限り紐付きは切れません。
- 存在しないカット ID を指すリンクは、シナリオ読み込み時のサーバ正規化で自動的に `null` に倒されます（dangling reference の保護）。

### ショートカットキー

ショートカットは「全般」「カット編集」「テロップ編集」「効果音編集」「再生・タイムライン」の 5 カテゴリに分かれています。同じ物理キー（例: `←` / `↑`）を複数のカテゴリで再利用でき、フォーカス位置（タイムライン canvas / それ以外）と現在の選択状態（編集対象がカット / テロップ / 効果音のいずれか）に応じて適切なアクションが発火します。下表は **既定値** です。すべて全体設定 → ショートカット タブで個別に変更 / 「なし」に設定できます。

#### 全般

| 既定キー | 動作 |
| --- | --- |
| `Space` | 再生 / 停止 |
| `R` | ループ再生を切替 (なし → カット → シーン → なし) |
| `Shift+D` | 選択を複製（カット / テロップ / 効果音いずれかを選択中の対象で動作） |
| `Backspace` | 選択を削除（同上。Undo で復帰可） |
| `N` | 現在のカットの末尾に新規カットを挿入 |

#### カット編集

| 既定キー | 動作 |
| --- | --- |
| `←` / `→` | 前 / 次のカットへ移動 |
| `Shift+←` / `Shift+→` | 選択を左 / 右へ広げる（複数カット選択） |
| `Alt+←` / `Alt+→` | 選択カットを前 / 後ろへ移動（並び替え） |

#### テロップ編集

タイムライン canvas にフォーカス (canvas クリックまたは Tab) した状態、または右パネルがテロップ編集モードのとき有効です。

| 既定キー | 動作 |
| --- | --- |
| `↑` / `↓` | 前 / 次のテロップを選択（重なりの有無は問わない） |
| `←` / `→` | テロップ選択中は ±1 frame 平行移動 |
| `S` | テロップ群の先頭、または直近のテロップ先頭を再生ヘッドに合わせる |
| `E` | 直近のテロップの終端を再生ヘッドに合わせる (1 frame snap あり) |

#### 効果音編集

右パネルが効果音編集モード (タイムラインの効果音帯から効果音を選択した状態) のとき有効です。`↑` / `↓` の既定キーはテロップ編集と同じですが、編集対象が効果音のときだけ発火します。

| 既定キー | 動作 |
| --- | --- |
| `↑` / `↓` | 前 / 次の効果音を選択 (startFrame 昇順) |

#### 再生・タイムライン

タイムライン canvas にフォーカスした状態で有効です。

| 既定キー | 動作 |
| --- | --- |
| `Shift+←` / `Shift+→` | 再生ヘッドを ±1 frame 移動 |
| `Shift+Alt+←` / `Shift+Alt+→` | 再生ヘッドを ±1 秒移動 |
| `Home` / `End` | 再生ヘッドを先頭 / 末尾へ |
| `←` / `→` | テロップ未選択時: 前 / 次のテロップ先頭へジャンプ |

#### OS 標準（変更不可）

| キー | 動作 |
| --- | --- |
| `Cmd/Ctrl+Z` | Undo |
| `Cmd/Ctrl+Shift+Z` / `Cmd/Ctrl+Y` | Redo |
| `Cmd/Ctrl+A` | タイムライン canvas にフォーカス時、全テロップ選択 |

ダイアログを開いている間や `<input>` / `<textarea>` にフォーカスがあるときは、上記ショートカットは OS の編集操作を優先します。

#### ショートカットの変更

`全体設定 → ショートカット` で各アクションのキーをクリックし、割当てたいキーを押してください。「クリア」で「なし」（無効化）、「初期値」で出荷時設定に戻せます。同じキーをカテゴリ別に重ねることもでき、フォーカスと選択状態で適切な側が発火します（例: `←` をカット編集ではそのまま、テロップ編集では「なし」に設定すれば、テロップ選択中の ±1 frame 平行移動だけ無効化できる）。

## ダッシュボード

ダッシュボードはプロジェクト一覧 + 補助操作の集約画面です。

- プロジェクト一覧 (検索・並び替え・新規・複製・名称変更・削除)
- 取り込み待ちの PSD と取り込み履歴
- ヘルプ (`/help/` でビルド済みドキュメント)
- 全体設定への入口

## 全体設定

ヘッダーの `全体設定` で開きます。左側に `動画書き出し` / `編集` / `環境` / `音声読み上げ` / `ショートカット` / `バックアップ` / `キャッシュ` のタブがあります。

| 項目 | タブ | 説明 |
| --- | --- | --- |
| 動画プリセット | 動画書き出し | 内蔵プリセット + ユーザープリセット (`customPresets`) |
| 既定の書き出しプリセット | 動画書き出し | 動画書き出しダイアログで初期選択するプリセット |
| モノラル → ステレオ | 動画書き出し | mono の音声を stereo にミックスダウンするか |
| 書き出しダイアログを毎回出す | 動画書き出し | 「動画出力」ボタンで毎回プリセット / fps を選ぶか |
| Undo 履歴サイズ | 編集 | 1〜500 |
| ffmpeg のパス | 環境 | 起動時に自動検出されるが、明示指定で固定可 |
| プロジェクトフォルダ | 環境 | `projects/` の代替先を絶対パスで指定 |
| 静音モード (quietMode) | 環境 | uvicorn のアクセスログを WARNING に抑制 |
| JS ライブラリのインストール | 環境 | three.js / mp4box.js を `static/vendor/` に取得 |
| CDN を使う | 環境 | ローカル vendor を無視して CDN を強制利用 (デバッグ用) |
| Noto Sans JP をインストール | 環境 | `notofonts/noto-cjk` の static OTF を 7 weight (Thin / Light / DemiLight / Regular / Medium / Bold / Black) `assets/fonts/NotoSansJP/` に取得 |
| フォント自動認識 | 環境 | `assets/fonts/` の各ファイルから OS/2.usWeightClass + name テーブルを読み、weight と表示名を自動判定。誤判定はファイル単位でドロップダウン上書き可 |
| VOICEVOX アプリのパス / URL | 音声読み上げ | 検出された VOICEVOX を使う場合は空欄でも可。別パスにインストール済みなら絶対パスを指定 |
| VOICEPEAK バイナリのパス | 音声読み上げ | VOICEPEAK の CLI バイナリのパス (mac は `.app` 配下、Windows は `voicepeak.exe`) |
| ボイスを登録 | 音声読み上げ | VOICEVOX の `/speakers` と VOICEPEAK の `--list-narrator` から話者・感情を取得して `app_state/voice_catalog.json` へ保存。VOICEVOX が起動していなければ自動で起動を試みる (最大 20 秒) |
| ショートカット一覧 | ショートカット | カテゴリ別 (全般 / カット / テロップ / 再生・タイムライン) に各アクションのキーを編集。クリアで「なし」、初期値で出荷時設定に戻る。`global_config.json` の `shortcuts` に保存 |
| 自動バックアップ間隔 / 保存件数 | バックアップ | `scenarios/main.json` の auto スナップショット (周期 + 切替時)。詳細は[プロジェクト設定 → バックアップ](./project-settings.md) |
| 起動時に古いキャッシュを自動削除 | キャッシュ | `cache/preview/` / `cache/lipsync/` / `cache/clean_pcm/` のうち mtime が指定日数より古いものを起動時に削除 (既定: ON / 30 日)。手動削除は [素材管理 → キャッシュタブ](./assets.md#キャッシュタブ) から |

設定は `~/.config` などではなく、リポジトリ直下の `app_state/global_config.json` に保存されます。

音声読み上げタブの詳しい使い方は [音声合成 (VOICEVOX / VOICEPEAK) を使う](../tutorials/voice-synthesis.md) を参照してください。
