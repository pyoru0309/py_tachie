# プロジェクト設定リファレンス

設定画面では、プロジェクト単位の **お芝居（文字）/ お芝居（セリフ枠）/ 演出 / テロップ / 動画 / 口パク解析** を変更できます。
設定は `projects/<project_id>/config.json` に保存されます。`保存` ボタンを押さずに `閉じる` でダイアログを閉じた場合、その間の入力は破棄され、次にダイアログを開いたときは保存済みの値が再表示されます。

このページではプロジェクト設定だけを扱います。アプリ全体の設定 (ffmpeg のパス / プロジェクトフォルダ / 動画プリセット / Undo 履歴 / quietMode 等) は [編集画面リファレンス](editor.md#全体設定) を参照してください。

各章の順序と見出しは設定画面の縦メニューと対応しています。

## お芝居（文字）

| 項目 | 初期値 | 説明 |
| --- | --- | --- |
| デフォルト書体 | `noto_sans_jp` | 新規カットで使う標準フォント |
| デフォルト太さ | `regular` | 新規カットで使う標準ウェイト |
| デフォルト文字サイズ | `54` | 新規カットで使う標準文字サイズ |
| テキスト色 | `#ffffff` | セリフ本文の色 |
| アウトライン色 | `#666666` | テキスト周囲のアウトライン色 |
| アウトライン幅 | `0` | アウトラインの太さ (px) |
| 文字間 (1/1000em) | `0` | -500〜+1000。すべての隣接文字に一律で加算する間隔。1/1000 em 単位でフォントサイズに比例するため、文字サイズを変えても見た目の字間バランスが変わらない |
| オプティカルカーニング | OFF | OFF / 標準 / 強め の 3 段切替 (詳細は下記) |
| セリフ文字の光彩 | OFF | セリフ本文に外側のぼかし発光を載せる。`色` + `ぼかし (0-200px)` + `強度 (0.0-1.0)` を持つ。カット単位の上書きが無いときの既定値 |
| セリフ文字のドロップシャドウ | OFF | セリフ本文に影を落とす。`色` + `ぼかし (0-200px)` + `強度 (0.0-1.0)` + `X 方向` / `Y 方向` (-200..200) を持つ。カット単位の上書きが無いときの既定値 |

セリフ文字エフェクトは「セリフ本文」だけに掛かり、話者名 / 装飾 PNG / セリフ枠は対象外です。プロジェクト設定で値を変更して保存すると、変更項目は **「すべてのカットに反映するか」確認ダイアログ** に含まれ、チェックを入れたカットの `textStyle.dialogueGlow` / `textStyle.dialogueDropShadow` に書き戻されます (`dialogueGlow` / `dialogueDropShadow` という単位での丸ごと反映)。

### オプティカルカーニング (お芝居 / テロップ共通)

フォント本体の `palt` テーブルに依存せず、各文字の **実ピクセル形状** から余白を測って隣接ペアを詰める機能です。OFF / 標準 / 強め の 3 つから 1 つを選びます。

詰めの対象は本文 (お芝居・テロップ) のみで、話者名は対象外です。詰めた **後に** `文字間 (1/1000em)` が一律加算されるため、「全体としてゆるく開けつつ punctuation だけ詰める」といった調整が同居できます。お芝居側の設定はセリフ本文に、テロップ側の設定はすべてのテロップに適用されます。

#### 標準モード

各文字の **左右ベアリング** (= ink の左端 / 右端の x 座標) と文字クラスごとの強度カーブを掛け合わせて **やや控えめ** に詰めます。括弧・句読点まわりは強く、漢字同士はかなり弱く、といった日本語の組版感に近い見た目になります。一般的な本文・テロップにはこちらが推奨です。左右ベアリングだけを使う軽量計算で、書き出し速度の影響はほぼありません。

#### 強めモード

各文字をオフスクリーンに焼いて **Y 行ごとの輪郭プロファイル** (左端 / 右端 / 字面密度 / 直線度) を抽出し、ペアの shift 候補を探索して **白場分布が最も自然な位置** を選びます。「`DJ`」「`鳴らせ`」のように bbox では捉えられない字形相性 (D の丸み / J の下のフック / ら の曲線 + せ の縦画 等) も Y 軸方向の距離分布として評価します。

スコアは「目標 gap からの偏差」「局所的に近すぎるペナルティ」「局所的に広すぎるペナルティ」の重み付き和で、最小値の shift を採用します。目標 gap は文字クラス (漢字+漢字 / かな同士 / 約物まわり 等)・字面密度・直線度から動的に決まり、「漢字 + かな」では空気を残しめ、「約物まわり」では狭めに、といった日本語向けの調整がかかります。

初回は 1 ペアあたりの shift 探索で数百 µs の計算が走りますが、結果は `(書体, 文字サイズ, 左の字, 右の字, アウトライン幅)` の単位でキャッシュされるため、同じテロップ・セリフを複数行使っていても再計算は走りません。

> **強めモードのリセット目安**
> 強めモードは積極的に詰めるため、書体や用途によっては「ベタ打ちのリズム」を保ちたくなる場面があります。その場合は **`文字間` を `+200`** (= 0.2em) ほど加えると、強めモードで詰めた量が概ね相殺されてベタ打ち相当の見た目に戻ります。組版用途のロゴやタイトルではここから少しずつ詰める / 広げると目当ての字間に追い込みやすいです。


## お芝居（セリフ枠）

| 項目 | 初期値 | 範囲 | 説明 |
| --- | --- | --- | --- |
| デフォルト帯の濃さ | `0.8` | 0.0-1.0 | セリフ枠背景の標準不透明度 |
| ボーダー太さ | `3` | 0-100 | セリフ枠の線幅。線は枠の **外側** に描画されるため、半透明の背景色とブレンドしません |
| ボーダー色 | `#ffffff` | 色 | セリフ枠の線色 |
| 背景色 | `#14181c` | 色 | セリフ枠の背景色 |
| 装飾画像 | 空 | 素材一覧 | セリフ枠に重ねる装飾画像。PNG / WebP / AVIF (透過) を扱えます。設定上部のセリフ枠プレビューに、`セリフ X / Y オフセット` を反映して 1920×1080 の素材からセリフ枠領域だけを切り出した状態で表示されます |
| セリフ X オフセット | `120` | 0-1920 | セリフ枠の水平方向オフセット |
| セリフ Y オフセット | `70` | 0-1080 | セリフ枠の垂直方向オフセット |
| セリフ枠余白 X | `60` | 0-400 | 枠内の左右余白 |
| セリフ枠余白 Y | `70` | 0-200 | 枠内の上下余白 |
| 2 段の行間 | `16` | 0-120 | 2 段表示時の行間 |
| 話者名サイズ | `28` | 12-80 | 話者名の文字サイズ |
| 非話者の暗さ | `0.5` | 0.0-0.9 | 話者以外のキャラに重ねる黒オーバーレイの濃さ。**0 で全く暗くしない**、`0.9` で最も暗くなります |
| 角丸 左上 (px) | `0` | 0-500 | セリフ枠左上の角丸半径 |
| 角丸 右上 (px) | `0` | 0-500 | セリフ枠右上の角丸半径 |
| 角丸 左下 (px) | `0` | 0-500 | セリフ枠左下の角丸半径 |
| 角丸 右下 (px) | `0` | 0-500 | セリフ枠右下の角丸半径 |

角丸は CSS の `border-radius` と同じく、隣接 2 角の合計が辺長を超えるときだけ全体を比率縮小します。各角は単独では枠の幅 / 高さの上限まで使えるため、たとえば左下と右下だけを大きく取ってドーム状の枠を作ったり、`セリフ枠余白 X` と組合せて 1/4 楕円風の表現を作ったりできます。

セリフ枠の各設定は **プロジェクト共通** です。設定保存と同時にすべてのカット (ライブプレビュー / 動画書き出し / サムネイル) に即時反映されるため、カット個別の指定は行いません。

## テロップ

テロップを新規追加したときに使う既定スタイルを `telopDefaults` に保存します。

| 項目 | 初期値 |
| --- | --- |
| 書体 | `noto_sans_jp` |
| 太さ | `regular` |
| 文字サイズ | `48` |
| 文字色 | `#ffffff` |
| アウトライン色 | `#000000` |
| アウトライン幅 | `4` |
| 字間 | `0` |
| 行間 | `0` (−500〜500px。負値で行を詰める / 重ねる。大きい文字サイズで行間が足りないとき用) |
| 文字揃え | `center` (テロップ編集パネルから `left` / `center` / `right` を選択可) |

| オプティカルカーニング | OFF |
| 光彩 (glow) | OFF |
| ドロップシャドウ | OFF |

テロップ編集パネルの `既定値に保存` で現在の値を `telopDefaults` に書き出し、`すべてのテロップに反映` で既存テロップへ一括適用できます。
変化のあった項目だけが反映されます。

## 動画

| 項目 | 初期値 | 説明 |
| --- | --- | --- |
| 目パチ | 有効 | MP4 出力時に目レイヤーを切り替える |
| 口パク | 有効 | MP4 出力時に音声 / セリフに合わせて口レイヤーを切り替える |
| 目パチ方式 | `アニメ方式` | 1 回の瞬きのフレーム配分。`アニメ方式` は「開き → 閉じ → 中 → 開き」のスナップ閉じ + 段階開き、`均等方式` は各 fps で短く均等な瞬き (中目なしのキャラはさらに短くなる)。詳細は [キャラクターモデル #目パチのフレーム配分](../technical/character-model.md#blink-frame-pattern) を参照 |
| 文字アニメ FPS | `12` | ライブプレビューでキャラアニメを量子化する fps (8 / 12 / 24) |

目パチの **タイミング** はキャラクター単位で独立にランダム化されます。2 人以上のキャラを同時に出しても全員が同じ瞬間に瞬くことはなく、各キャラごとに別々の間隔で目パチが入ります。ライブプレビューは再生のたびに完全ランダム (再現性なし)、書き出しは `cut.id + 表示時間 + char.id` を seed にした deterministic な乱数を使うため、同じプロジェクトを再書き出ししても結果は同じです。

## フォント

フォントは共通の `assets/fonts/` とプロジェクト内の `assets/fonts/` から自動認識されます。対応拡張子は `.otf` と `.ttf`。

### 認識のしくみ (2026-05 改修)

それぞれのフォントについて次の情報を読み出し、UI 表示用の family 名と太さ (weight) を確定します。

- **太さ**: OS/2 テーブルの `usWeightClass` (= フォント自身が宣言する重み) を最優先。読めなければファイル名末尾 (`Bold` / `Medium` / `Regular` / `Thin` / `Black` 等) でフォールバックし、最後は `regular` とします。
- **family 名 (UI 表示)**: name テーブルから次の順で読み出します。
    1. ja-JP / Mac-ja (= 日本語 family 名)
    2. en-US / Mac-en
    3. ファイル名 (拡張子と weight suffix を除いた部分)

  これにより、たとえば `NekoSpoon.otf` → 「ねこスプーン」、`APJapanesefont.ttf` → 「あんずもじ」、`HuiFont29.ttf` → 「ふい字」のように、FontBook と同じく日本語名で識別できます。
- **family ID (永続キー)**: scenario JSON や設定ファイルが参照する内部 ID は **ファイル名 stem 由来** で固定 (`auto_<ascii_slug>`)。純日本語ファイル名のように ASCII 文字がまったく含まれない stem では SHA1 先頭 8 文字をハッシュ化して `auto_<8hex>` を付与します (例: `花とちょうちょ.ttf` → `auto_4785310d`)。これは複数の日本語ファイル名が同じ `auto_unnamed` に潰れて 1 エントリにマージされていた不具合の対処です。

### 太さ ID の上書き

OS/2 値が不正確なフォント (例: 「Bold」と書いてあるのに usWeightClass=400) は、全体設定 → フォントのテーブルで weight を手動上書きできます。`fontWeightOverrides[<rel_path>]` として global config に保存されます。

ライブプレビューでは manifest 上のフォント情報を `FontFace` として登録するため、サーバの Pillow とブラウザの canvas が同じ書体で描画されます。

## 表情プリセット

頬 + 目 + 口 の組み合わせを名前付きで保存します。プリセットはキャラクター ID ごとに紐付くため、編集画面では選択中キャラ向けのプリセットだけが表示されます。

- **アセット側** (`assets/characters/<id>/expression_presets.json`): 配布用の正本。アセット管理ダイアログ → 表情プリセット (mood アイコン) で編集します。`isDefault` を立てたプリセットは新規キャラ追加時に自動選択されます。
- **プロジェクト側** (`projects/<id>/expression_presets.json`): プロジェクト固有の override。編集画面のセリフタブ「表情プリセット」セレクタ横の `保存` で書き込めます (共通キャラでも保存可能)。アセット由来プリセットを選択した状態で組合せを変更し保存すると、同 ID で project override が作成されます。

カット編集の表情プリセットセレクタにはアセット + プロジェクト両者がマージされて表示され、アセット由来は `(アセット)` 表示・削除不可、デフォルトは `★` 付きで識別できます。詳細は [キャラクターモデル](../technical/character-model.md#expression-presets) を参照してください。

## 髪型プリセット

ベース + 前髪 + 後ろ髪 の組み合わせはアセット定義のみで完結します (プロジェクト固有上書きは持ちません)。アセット管理ダイアログ → 髪型プリセット (content_cut アイコン) で編集します。

カット内のキャラの「髪型」セレクタはここで定義したプリセットだけを参照し、`hairstylePresetId` でカット状態に保存されます。詳細は [キャラクターモデル](../technical/character-model.md#hairstyle-presets) を参照してください。
