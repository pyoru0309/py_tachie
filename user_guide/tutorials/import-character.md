# キャラクターをインポートする

立ち絵システムでは、キャラクター素材を 7 カテゴリ (`back_hair` / `base` / `cheek` / `eye` / `mouth` / `bangs` / `front`) に固定して扱います。
ダッシュボードの PSD インポータ、または `キャラ管理` から、PSD・階層 PNG/WebP フォルダ・ZIP のいずれかを取り込めます。

## PSD から取り込む (推奨)

1 枚の PSD に差分レイヤーをまとめておく運用が一番ラクです。
PSD のレイヤー命名は [PSD レイヤー命名規則](../technical/psd-layer-rules.md) を参照してください。

1. ダッシュボードを開き、`PSD インポート` を押します。
2. 取り込みたい PSD をドラッグ & ドロップ、またはファイル選択で指定します。
3. プレビューに PSD のレイヤーツリーが表示されます。レイヤー名 / ID は変更されず、PSD のまま `eye/` `mouth/` などのカテゴリへ振り分けられます。
4. **登録先**: 「共通アセット」(`assets/characters/<id>/`) と「プロジェクト」(`projects/<project_id>/assets/characters/<id>/`) のどちらに保存するかを選びます。既定は **共通アセット**。プロジェクト未選択時はプロジェクト側は無効化されます。
5. レイヤーを **重なり順 (上が前面、下が背面)** に並んだ登録ボタンで分類します: `サムネイル → 前面 → 前髪 → 目 → 口 → 頬 → ベース → 後ろ髪`。マッピング YAML の出力もこの並びに揃います。
6. 取り込み設定を選びます。
   - **出力フォーマット**: `png` (可逆) か `avif` (Pillow 12+ ネイティブ。容量 1/30〜1/40)
   - **縦上限 px / 横上限 px**: `0` は無制限。等倍縮小される
   - **補間アルゴリズム**: `lanczos` / `bicubic` / `hamming` / `bilinear` / `box` / `nearest`
   - **追記 (append)**: 既存キャラに新しいレイヤーだけ足したい場合に ON。append 時は `登録先` 選択は無効化され、選択中のキャラディレクトリにマージされます
7. `インポート` を押すと、ステップ 4 で選んだ場所の `<character_id>/` 配下に展開されます。
8. PSD 内のレイヤー名が `thumb` / `thumbnail` / `サムネイル` / `サムネ` であれば、キャラサムネイル (`thumb.png`) として自動で書き出されます。

プレビュー領域は読み込み直後にフィット表示 (枠内に画像全体が収まる縮小率) になり、虫眼鏡の `+` で拡大したときだけスクロールバーが現れます。`フィット` ボタンでいつでも初期表示に戻せます。

取り込み完了後、編集画面の `素材キャラ` セレクタに新しいキャラクターが現れます。次回の取り込みでは、保存された `import_manifest.yml` が自動で読み戻されます。

PSD のルート直下に `import_manifest.yml` という名前の **テキストレイヤー** を置いて YAML 本文を書いておくと、PSD 1 枚で flags / 表情プリセット / 髪型プリセットまで配布できます。詳細は [PSD レイヤー命名規則 → import_manifest.yml](../technical/psd-layer-rules.md#import-manifest-yml) を参照してください。

## 目パチ・口パクのフラグを設定する

インポート直後の状態では、目パチ・口パクの動作対象レイヤーが指定されていないため、目はカット選択のまま固定 / 口は無音時の表情で固定 になります。次の手順で動かします。

1. 編集画面の `キャラ管理` (またはダッシュボードの該当キャラから `レイヤー編集`) を開きます。
2. **目** セクションの各行のチェックボックスで以下を立てます:
    - 普通に開いている目 / 驚いた目など、**目パチさせたい** すべての目に `開き` (= `blinkOpen`)
    - 中間フレーム用 (任意): 半目素材があれば `中間` (= `blinkHalf`)
    - 閉じフレーム: 閉じ目素材に `閉じ` (= `blinkClosed`)
3. **口** セクションも同様に `閉じ` / `中間` / `開き` (= `lipClosed` / `lipMid` / `lipOpen`) を 1 枚ずつ立てます。
4. 各レイヤー行の **表示名 input** で UI 上の名前を読みやすく直せます (例: `制服_デフォルト` → `制服 (通常)`)。レイヤー ID は不変なのでシナリオの参照は壊れません。
5. `保存` を押すと `character_manifest.json` の各エントリに `name` / `flags` が書き込まれ、`import_manifest.yml` も透過的に同期更新されます。

笑い目・ウインク目など、目パチさせたくない目には `開き` を立てません。これでカットでそれらの表情を選んだときは、目パチをスキップして表情が維持されます。動作の詳細は [キャラクターモデル](../technical/character-model.md#blink-lipsync-flags) を参照してください。

## 階層 PNG/WebP フォルダから取り込む

PSD を持っていない場合は、カテゴリ別フォルダに分けた PNG/WebP 一式を ZIP にして取り込みます。最小構成は `base/` の画像 1 枚です。

```text
sample_character.zip
  back_hair/
    long.png
  base/
    default.png
    uniform_pose1.png
  cheek/
    blush.png
  eye/
    open.png
    half.png
    closed.png
  mouth/
    closed.png
    mid.png
    open.png
  bangs/
    default.png
  front/
    hand_front.png
  thumb.png                  (任意。サムネイル)
  import_manifest.yml        (任意。flags / 表情・髪型プリセットを含めた配布マニフェスト)
```

1. `キャラ管理` を開きます。
2. `インポート` タブを選びます。
3. キャラ ID と表示名を入力します (ID は半角英数字とハイフン)。
4. PSD ・ ZIP ・ フォルダのいずれかを指定します。
5. `インポート` を押します。

## 取り込み後の確認

- 編集画面の `キャラ配置` タブから、表示名・既定 X / Y / 拡大率・白背景透過を編集できます。
- **既定 X の自動算出**: PSD インポート時に「インポート後の横幅」から `(1920 - 横幅) / 2` を計算して、キャラ定義の既定 X に書き込みます。例えば 1440 px で取り込むと既定 X は `240`、1920 px なら `0`。これでキャラの中央寄せが最初から効きます。既定 Y は `0` (上端) で固定。
- 線画キャラで黒線をなじませたい場合は、PSD インポータダイアログ下部の **黒線アンチエイリアス** チェックボックスを ON にして取り込んでください。プリセット (シャープ / 標準 / ソフト / マイルド / 太線対応) で雰囲気を選べます。詳細は [キャラクターモデル: 黒線アンチエイリアス](../technical/character-model.md#黒線アンチエイリアス-psd-インポート時に焼き込み) を参照。
- `素材キャラ` セレクタで選択 → `追加` でカットに登場させます。
- 登場後、選択中キャラの体 (`base`)、頬 (`cheek`)、目 (`eye`)、口 (`mouth`)、髪型 (`hairstylePresetId` 経由で `bangs` + `back_hair` + `base` をまとめて切替)、前面 (`front`、複数可) を切り替えられます。

## 表情プリセット / 髪型プリセットを配布アセットに含める

ダッシュボード → アセット管理 → キャラクターカードの :material-emoticon-outline: アイコンで **表情プリセット** (頬+目+口)、:material-content-cut: アイコンで **髪型プリセット** (ベース+前髪+後ろ髪) をそれぞれ編集できます。

- アセット側に保存したプリセットは、すべてのプロジェクトで自動的に読み込まれます。
- `デフォルト` を 1 つ立てておくと、新規キャラ追加時に自動選択されます。
- 詳細は [キャラクターモデル](../technical/character-model.md#expression-presets) を参照してください。

## eyeAboveBangs (前髪と目の前後関係)

通常のキャラクターは `bangs` (前髪) を目の前に重ねますが、目だけ前髪より上に出したい演出のときは、カット単位の `eyeAboveBangs` フラグを ON にしてください。`back_hair` → `base` → `cheek` → `bangs` → `eye` → `mouth` → `front` の順で焼き直されます。

## 共通キャラとプロジェクト固有キャラ

- `assets/characters/<id>/` に置いたキャラは、すべてのプロジェクトから参照できる共通素材として扱われます。レイヤー定義 (画像・flags・name) と髪型プリセットは編集画面では書き換えできず、ダッシュボード → アセット管理から編集する必要があります。表情プリセットは編集画面でも project override として保存できます (アセット側ファイルは無傷)。
- `projects/<project_id>/assets/characters/<id>/` に置いたキャラは、そのプロジェクト内でのみ編集・削除できます。
- PSD インポータの **登録先** で「共通アセット」を選ぶと `assets/characters/<id>/` に、「プロジェクト」を選ぶと `projects/<project_id>/assets/characters/<id>/` に保存されます。既定は共通アセットです。後から昇格 / 降格させたいときは、対応するディレクトリへ手動で移動してください。

## 音声合成アプリと紐付ける

ダッシュボードまたは編集画面の `キャラ管理` で各キャラに **声** と **感情** (VOICEPEAK のみ) を紐付けると、編集画面で「話者」を選んだだけで自動的にその声が選択されます。詳細は [音声合成 (VOICEVOX / VOICEPEAK) を使う](voice-synthesis.md) を参照してください。
