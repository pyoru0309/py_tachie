# プロジェクトを作成する

プロジェクトは、シナリオ、設定、表情プリセット、プロジェクト固有素材、出力ファイルをまとめる単位です。
作品単位、動画シリーズ単位、キャラクター検証単位など、管理したい範囲ごとに分けて作成します。

## 新規プロジェクト

1. ヘッダーの `新規`、またはダッシュボード / プロジェクト一覧の `新規プロジェクト` を押します。
2. プロジェクト名を入力します。
3. `保存` を押します。

プロジェクト ID は入力名をもとに半角英数字 + ハイフンへ正規化されます。同じ ID がすでに存在する場合は、末尾に番号が付いた別 ID になります。
作成直後に `projects/<project_id>/project.json` / `config.json` / `scenarios/main.json` が生成されます。

## プロジェクト一覧

ヘッダー左のプロジェクト名 → `プロジェクト一覧`、またはダッシュボードから一覧を開けます。

| 項目 | 用途 |
| --- | --- |
| 名称フィルタ | プロジェクト名で絞り込み |
| 日付フィルタ | 指定日に作成・更新されたプロジェクトを抽出 |
| 保管場所 | 保管場所で絞り込み (保管場所を 2 つ以上登録しているときだけ表示) |
| 並び順 | 最近開いた順 / 更新日時順 / 名称順 / 作成日時順 |
| サムネイル | カードに表示するキャラクターサムネイル (`projects/<id>/thumb.png`) |

各カードからは `開く` / `名称変更` / `複製` / `移動` / `アーカイブ` / `削除` を実行できます (`移動` は保管場所を 2 つ以上登録しているときだけ出ます)。
ダッシュボード上部のツールバーには `新規プロジェクト` / `読み込み` (ZIP 取り込み) もあります。

## プロジェクトを切り替える

ヘッダーのプロジェクト選択メニュー、または一覧画面からの `開く` で切り替わります。
切替時にはライブプレビューの再生が停止し、対象プロジェクトのシナリオ・設定・素材一覧が読み込まれます。

## 名称変更

プロジェクト一覧 → 対象カードの `名称変更` で表示名を更新できます。
ディスク上のフォルダ名 (プロジェクト ID) も新しい名前に追従して変更されます。
他プロジェクトと ID が衝突する場合は末尾に `_2`, `_3`, ... の連番が付きます。

## 複製

プロジェクトカードの `複製` で、**プロジェクトフォルダをまるごとコピー**します。新しい ID は自動で採番されます。
保管場所を複数登録している場合は、ダイアログで複製先の保管場所も選べます。

コピーされるもの / されないものは次のとおりです。

| | 複製先 |
| --- | --- |
| シナリオ・設定・プリセット・プロジェクト固有素材 | ✅ コピーされる |
| `outputs/` (書き出した動画 / PNG / 字幕、手で置いたサムネや過去バージョン) | ✅ 既定でコピーされる（ダイアログのチェックを外すと省けます） |
| フォルダ内に Finder / エクスプローラーで手作業で置いたファイル・フォルダ | ✅ コピーされる |
| `cache/` (プレビューキャッシュ) | ❌ コピーされない |

`cache/` だけはコピーしません。プレビューキャッシュはプロジェクト ID を含むキーで引くので、ID が変わる複製先では 1 枚も再利用できず、容量を食うだけになるためです（必要な分は次の再生時に作り直されます）。

除外の対象は**プロジェクト直下の `cache/` / `outputs/` だけ**です。`参考資料/cache/` のように自分で作ったフォルダの中に同じ名前があっても、それは巻き添えになりません。

複製ダイアログには、そのプロジェクトの合計容量と `outputs/` の容量が表示されます。

## アーカイブ (ZIP 書き出し)

プロジェクトカードの `アーカイブ` を押すと、プロジェクトディレクトリ全体を `<タイトル>.splite.zip` としてダウンロードできます。
ファイル名にはプロジェクト名がそのまま入ります (日本語だけの名前でもそのまま残ります)。

- 中身: `project.json` / `config.json` / `expression_presets.json` / `scenarios/` / `assets/` (= プロジェクト固有素材)
- 除外: `cache/` / `outputs/` / `exports/` / `generated/` (派生物・揮発キャッシュ)

共通アセット (`assets/characters/<id>/` など、プロジェクト外の `assets/`) は zip に含まれません。完全なバックアップが必要な場合はリポジトリ全体を別途バックアップしてください。

## 読み込み (ZIP 取り込み)

ダッシュボード上部のツールバー → `読み込み` で、上記 ZIP を取り込めます。

- 取り込み先 ID は ZIP 内の `project.json` に書かれた ID をベースに採番。既存と被ったら `_2`, `_3`, ... と自動でずれます (上書きされません)。
- スキーマバージョンが古い場合は取り込み時に自動的に最新へ更新します (`app/project_import.py` の `MIGRATIONS` を順次適用)。
- 取り込み後はトーストに `v3 → v4` のような表記が出ます。

## 保管場所 (複数のフォルダにプロジェクトを分ける)

プロジェクトの置き場所は複数登録できます。完成した作品を外付けディスクへ寄せても、プロジェクト一覧からはこれまでどおり開けます。

### 保管場所を登録する

`全体設定` → `環境` → **プロジェクトの保管場所** で、表示名とフォルダの絶対パスを入力して `保管場所を追加` を押します。
`フォルダが無ければ作成する` にチェックを入れておくと、親フォルダが存在する場合にかぎりフォルダを作ります (未接続の外付けディスクのパスに対して、起動ディスク側へ空フォルダを作ってしまわないための制限です)。

各保管場所の行からは次の操作ができます。

| 操作 | 内容 |
| --- | --- |
| 新規の保存先にする | 以降の `新規プロジェクト` と ZIP 取り込みがこの保管場所に作られます |
| 名称変更 | 一覧やダイアログでの表示名を変えます |
| 登録解除 | **一覧に出さなくするだけ**で、ディスク上のファイルは一切削除しません。再登録すればそのまま戻ります |

一番上の「アプリ内 (既定)」は組み込みの保管場所で、削除できません。そのパスは下の **組み込み保管場所のパス** (旧「プロジェクトフォルダの場所」) で変更できます。既定は `projects/` (リポジトリルート) です。

### プロジェクトを移動する

プロジェクトカードの `移動` で、別の保管場所へ移します。**フォルダをそのまま動かすので、中身は一切間引きません。**

- 書き出した動画・字幕、Finder / エクスプローラーで手作業で置いたサムネやメモ、プレビューキャッシュまで、フォルダの中身は全部そのまま移動先へ移ります（移動は元フォルダを消すので、落とすものがあってはいけないためです）。
- シナリオ・素材の参照もそのまま引き継がれるので、移動後もそのまま編集できます。
- 同じディスク内の移動は一瞬です。別のディスクへ移すときは中身のコピーになるため、容量に応じて時間がかかります。
- 移動先に同じフォルダ名のプロジェクトがある場合は、末尾に `_2`, `_3`, ... の連番を付けて退避します。
- 編集中のプロジェクトを移動しても、そのまま開いたままになります。

### 外付けディスクを外しているとき

未接続の保管場所は設定画面で `未接続` と表示され、そこにあるプロジェクトは一覧に出ません。
プロジェクト一覧の先頭にも「未接続の保管場所があります」と理由が出るので、ディスクを繋ぎ直せばそのまま戻ります (設定を消す必要はありません)。

> **フォルダ名は全保管場所で重複させないでください。** プロジェクト ID (= フォルダ名) は素材パスの参照キーでもあるため、同じ名前のフォルダが複数の保管場所にあると先に見つかった方だけが使われます。その場合は一覧の先頭と設定画面に警告が出るので、どちらかのフォルダ名を変更してください (アプリ内の `移動` / `複製` / `読み込み` は自動で重複を避けます)。

## 削除

プロジェクトカードの `削除` を押すと確認ダイアログが開きます。確認欄にプロジェクト名または ID を入力し、`削除` を押すと、プロジェクト配下の素材・シナリオ・出力・キャッシュもまとめて削除されます。共通素材 (`assets/`) は削除されません。

## 自動保存

カット・テロップ・キャラクター配置などの編集はすべて自動保存されます。
ライブプレビューの再生ヘッド位置 (`lastPlayheadFrame`) もプロジェクトに保存され、次回起動時に復元されます。
編集中にネットワークが切れた場合や保存が失敗した場合は、画面右下にトーストで通知されます。
