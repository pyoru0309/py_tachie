# プロジェクトを作成する

プロジェクトは、シナリオ、設定、表情プリセット、プロジェクト固有素材、出力ファイルをまとめる単位です。
作品単位、動画シリーズ単位、キャラクター検証単位など、管理したい範囲ごとに分けて作成します。

## 新規プロジェクト

1. ヘッダーの `新規`、またはダッシュボード / プロジェクト一覧の `新規プロジェクト` を押します。
2. プロジェクト名を入力します。
3. `保存` を押します。

プロジェクト ID は入力名をもとに半角英数字 + ハイフンへ正規化されます。同じ ID がすでに存在する場合は、末尾に番号が付いた別 ID になります。
作成直後に `projects/<project_id>/project.json` / `config.json` / `scenarios/main.json` が生成されます。

## プロジェクト一覧

ヘッダー左のプロジェクト名 → `プロジェクト一覧`、またはダッシュボードから一覧を開けます。

| 項目 | 用途 |
| --- | --- |
| 名称フィルタ | プロジェクト名で絞り込み |
| 日付フィルタ | 指定日に作成・更新されたプロジェクトを抽出 |
| 並び順 | 最近開いた順 / 更新日時順 / 名称順 / 作成日時順 |
| サムネイル | カードに表示するキャラクターサムネイル (`projects/<id>/thumb.png`) |

各カードからは `開く` / `名称変更` / `複製` / `アーカイブ` / `削除` を実行できます。
ダッシュボード上部のツールバーには `新規プロジェクト` / `読み込み` (ZIP 取り込み) もあります。

## プロジェクトを切り替える

ヘッダーのプロジェクト選択メニュー、または一覧画面からの `開く` で切り替わります。
切替時にはライブプレビューの再生が停止し、対象プロジェクトのシナリオ・設定・素材一覧が読み込まれます。

## 名称変更

プロジェクト一覧 → 対象カードの `名称変更` で表示名を更新できます。
ディスク上のフォルダ名 (プロジェクト ID) も新しい名前に追従して変更されます。
他プロジェクトと ID が衝突する場合は末尾に `_2`, `_3`, ... の連番が付きます。

## 複製

プロジェクトカードの `複製` で、現在のシナリオ・設定・固有素材を含む完全なコピーを作成します。新しい ID は自動で採番されます。

## アーカイブ (ZIP 書き出し)

プロジェクトカードの `アーカイブ` を押すと、プロジェクトディレクトリ全体を `<タイトル>.splite.zip` としてダウンロードできます。

- 中身: `project.json` / `config.json` / `expression_presets.json` / `scenarios/` / `assets/` (= プロジェクト固有素材)
- 除外: `cache/` / `outputs/` / `exports/` / `generated/` (派生物・揮発キャッシュ)

共通アセット (`assets/characters/<id>/` など、プロジェクト外の `assets/`) は zip に含まれません。完全なバックアップが必要な場合はリポジトリ全体を別途バックアップしてください。

## 読み込み (ZIP 取り込み)

ダッシュボード上部のツールバー → `読み込み` で、上記 ZIP を取り込めます。

- 取り込み先 ID は ZIP 内の `project.json` に書かれた ID をベースに採番。既存と被ったら `_2`, `_3`, ... と自動でずれます (上書きされません)。
- スキーマバージョンが古い場合は取り込み時に自動的に最新へ更新します (`app/project_import.py` の `MIGRATIONS` を順次適用)。
- 取り込み後はトーストに `v3 → v4` のような表記が出ます。

## プロジェクトフォルダの保存先

既定では `projects/` (リポジトリルート) が使われますが、ヘッダーの `設定` → `全体設定` から `プロジェクトフォルダ` を絶対パスで指定し、外部 SSD やクラウド同期フォルダに移すこともできます。
パスを変更したらサーバを再起動してください。

## 削除

プロジェクトカードの `削除` を押すと確認ダイアログが開きます。確認欄にプロジェクト名または ID を入力し、`削除` を押すと、プロジェクト配下の素材・シナリオ・出力・キャッシュもまとめて削除されます。共通素材 (`assets/`) は削除されません。

## 自動保存

カット・テロップ・キャラクター配置などの編集はすべて自動保存されます。
ライブプレビューの再生ヘッド位置 (`lastPlayheadFrame`) もプロジェクトに保存され、次回起動時に復元されます。
編集中にネットワークが切れた場合や保存が失敗した場合は、画面右下にトーストで通知されます。
