# 音声合成 (VOICEVOX / VOICEPEAK) を使う

立ち絵システムには、編集画面から **VOICEVOX** または **VOICEPEAK** を直接呼び出してセリフ音声を作る機能が組み込まれています。
カットごとに「声」「感情」を選んで `音声を再生成` を押すだけで wav が生成され、そのカットの音声として紐付きます。
セリフを書き出した YAML に `voice` を含めれば、一括で何十カットぶんの音声を作ることもできます。

このチュートリアルでは、両アプリのセットアップから一括生成までの手順を一通り紹介します。

## 前提

- VOICEVOX または VOICEPEAK を **手元の PC にインストール済み** であること。
- VOICEVOX を使う場合は、合成中に VOICEVOX Engine が起動している必要があります (アプリを開いた状態 / 起動済みになっているとプログラムから利用可能)。立ち絵システム側からの自動起動も可能です。
- VOICEPEAK は CLI を使うので、アプリを起動していなくても動作します。

立ち絵システムがどちらも検出できなかった場合、関連する UI (「ボイスを登録」「声」「感情」「音声を再生成」「YAML 一括登録の自動生成チェック」) は無効化されます。

## 1. アプリのパスを確認 / 指定する

ヘッダーの **全体設定** → 左の **音声読み上げ** タブを開きます。

| 項目 | 既定の自動検出先 |
| --- | --- |
| VOICEVOX アプリのパス | macOS: `/Applications/VOICEVOX.app` / Windows: `C:\Users\<ユーザー名>\AppData\Local\Programs\VOICEVOX\VOICEVOX.exe` |
| VOICEVOX Engine の URL | `http://127.0.0.1:50021` |
| VOICEPEAK バイナリのパス | macOS: `/Applications/voicepeak.app/Contents/MacOS/voicepeak` / Windows: `C:\Program Files\VOICEPEAK\voicepeak.exe` |

入力欄の placeholder に「自動検出: ...」と出ていれば、空欄のままで自動検出パスが使われます。検出されなかったり、別の場所にインストールしている場合だけ絶対パスを書き込んでください。

## 2. ボイスを登録する

`音声読み上げ` タブの下にある **ボイスを登録** ボタンを押します。立ち絵システムは次を順に行います。

1. VOICEVOX のアプリパスが検出済みで Engine が応答していなければ、自動でアプリを起動 → `/version` の応答を最大 20 秒待つ (mac は `open <app>`、Windows は detached プロセスとして Popen)。
2. VOICEVOX `/speakers` から話者・スタイル一覧を取得。
3. VOICEPEAK の CLI から `--list-narrator` と各話者の `--list-emotion` を取得。
4. 取得結果を `app_state/voice_catalog.json` に永続化。
5. 既存のキャラ紐付けに残っている古い voice ID 形式 (`voicevox:8` など) を、新形式 (`voicevox:四国めたん/ノーマル`) に自動マイグレートして書き戻す。

成功すれば「音声カタログを更新しました（131 件）」のようなトーストが出ます。アプリのアップデートで話者が増減したり、VOICEPEAK の追加音源を購入した場合は、もう一度押し直してください。

> 「ボイスを登録」の所要時間: VOICEVOX 起動が必要な場合は最大 20 秒、起動済みなら 1〜2 秒。VOICEPEAK の `--list-emotion` は話者ごとに 1 回ずつ呼ぶので 4〜5 秒かかります。

## 3. キャラクターに声を紐付ける

ダッシュボードまたは編集画面から **キャラ管理** を開き、対象キャラをクリックして詳細ダイアログを開きます。
**音声アプリと紐付け** セクションで次を選びます。

- **声**: 例 `春日部つむぎ（ノーマル） (VOICEVOX)` / `Miyamai Moca (VOICEPEAK)`
- **感情**: VOICEPEAK の話者だけ有効。VOICEVOX には感情パラメータが無いので無効化されます。

「未設定」のままにすればそのキャラには紐付けなし扱いになります。

設定は `character_manifest.json` の `voice` フィールドとして永続化されます。共通キャラ・プロジェクト固有キャラのどちらでも紐付け可能です。

## 4. 編集画面で 1 カットだけ音声を作る

「お芝居」タブの **セリフ** セクションに、`声` / `感情` セレクタと **音声を再生成** ボタンが並びます。

1. **話者** を選ぶ。紐付け済みのキャラなら、声と感情のセレクタが自動で同期します。
2. その場で別の声に上書きすることも可能 (例: ナレーション用に話者と異なる声で読ませたい時)。
3. **音声を再生成** を押す。
   - VOICEVOX が落ちていれば、立ち絵システムが起動を試みます (15 秒タイムアウト)。
   - 生成された wav は `projects/<project_id>/assets/audio/tts/<cut番号>-<セリフ先頭>-<話者名>-<感情>-<YYMMDD-HHMMSS>.wav` に保存され、そのカットの音声として紐付き、表示時間も wav の長さに合わせて自動更新されます。

`音声` セレクタで素材から手動で選んだ音声 (TTS 以外の素材) も従来どおり使えます。両者は併用可能です。

## 5. YAML 一括登録で大量に作る

セリフを書き出した YAML を編集して **カット一括追加** から流し込むと、数十カットぶんの音声を一度に生成できます。
ヘッダーの **エクスポート** で書き出される `projects/<id>/export/<タイムスタンプ>-serif.yaml` がそのまま雛形になります。

### 書き出される YAML の形

```yaml
# セリフ書き出し
# 生成: 2026-05-06T15:25:42
# プロジェクト: my_project
# フィールド: index / speaker / voice / duration_sec / text
# - speaker は cut 内の登場キャラ ID (character_XXXX)。絵の再現のため変更しない。
# - voice はキャラ→音声アプリの紐付けから自動付与。形式は
#   'voicevox:四国めたん/ノーマル' / 'voicepeak:Miyamai Moca' のように
#   先頭にアプリ名 prefix を含む。VOICEPEAK は感情を含めて
#   'voicepeak:Miyamai Moca/honwaka' とも書ける。未紐付けは空欄。
# - duration_sec は「お芝居」タブの『表示時間』を秒に直したもの。
# - 一括追加で読み込むときに pause_sec: 0.5 を追記すればそのカットだけ尺を伸ばせる。

- index: 1
  speaker: character_1777865535610_2
  voice: 'voicevox:春日部つむぎ/ノーマル'
  duration_sec: 2.50
  text: |
    今日からこの教室で一緒に頑張ろう！
- index: 2
  speaker: character_1777865535610_3
  voice: 'voicepeak:Miyamai Moca/honwaka'
  duration_sec: 1.80
  text: |
    ふんわり喋ります。
```

### フィールドの意味

| 項目 | 内容 |
| --- | --- |
| `index` | 連番。書き出し時に自動採番されます。一括取り込み時は順序の確認用に使い、生成カットの ID には反映されません。 |
| `speaker` | カット内の **登場キャラインスタンス ID** (`character_XXXX_n`)。絵の再現のためそのまま維持してください。編集画面の「キャラ配置」タブの `登場キャラ` ラベル横にも表示されます (クリックでコピー可)。 |
| `voice` | アプリ名 prefix 付きの voice ID。`voicevox:{話者}/{スタイル名}` または `voicepeak:{話者}` (感情なし) / `voicepeak:{話者}/{感情}` (感情あり)。未紐付けカットは空欄。 |
| `duration_sec` | 「お芝居」タブの **表示時間** を秒に直したもの。手動編集で長さを調整可能。 |
| `text` | セリフ本文。YAML literal block (`|`) で改行を保持。 |

> **手書き時のポイント**: voice には必ず `voicevox:` または `voicepeak:` prefix を付けてください。VOICEVOX の数値 ID (`voicevox:8` など) は順序依存で再現性が無いため、新規には使えません。VOICEPEAK で感情を指定するときは `voicepeak:Miyamai Moca/honwaka` のように `/` でつなぎます。

### 追加で書ける任意フィールド

| 項目 | 内容 |
| --- | --- |
| `pause_sec` | 数値 (秒)。そのカットの表示時間に追加で「間」を足したいときに指定。例: 音声 2.0 秒 + pause 0.5 秒 → 表示時間 2.5 秒。 |

`emotion:` は廃止されました。VOICEPEAK の感情は voice に `/honwaka` のように含めてください。手書きで `emotion:` だけが書かれている場合は後方の保険として読み取ります。

### 一括登録の手順

1. テンプレートにしたい現在のカットを選択 (キャラ配置 / 背景 / モーションがそのまま継承されます)。
2. ヘッダーの **エクスポート** でセリフ YAML を書き出す。テキストエディタで開いて、追加カット分を編集 / 増やす。
3. 編集画面で **+ ボタン → カットを一括追加** を開く。
4. **YAML から一括登録** ラジオを選び、テキストエリアに YAML を貼り付ける。
5. **音声を自動で作成する** にチェックを入れる (VOICEVOX / VOICEPEAK が両方未検出ならこのチェックは無効になります)。
6. **上記の内容で一括登録** を押す。

進捗エリアにカットごとの状況とログが流れます。voice 欠落のカットは生成スキップ (テキストだけのカットとして登録)、voice 形式が不正な行は警告に出てカット追加自体もスキップされます。

### テキストモード (改行区切り)

YAML を書くのが大変なときは、**テキスト** タブから「1 行 = 1 セリフ」で流し込めます。

- 行頭に `話者ID:セリフ` または `話者名:セリフ` と書くと、その行のカットの話者が自動で切り替わります。区切り文字は半角「:」と全角「：」のどちらでも構いません。同じ表示名のキャラが複数いる場合は、現在のカットで前面側のレイヤーにいる方が選ばれます。
- 行頭にプレフィックスが無い行は、現在のカットの話者がそのまま使われます。
- **音声を自動で作成する** をチェックすると、各カットの話者に紐付いた声 / 感情で wav を生成します。話者の音声紐付けが無いカットは生成スキップ (テキストだけ登録)。
- **指定秒数の余白を入れる** をチェックすると 0.1 秒刻みで指定した秒数ぶん、各カットの表示時間を「音声長 + 指定秒数」に伸ばします (TTS と組み合わせると一拍置いたタイミングを作れます)。

### `pause_sec` の典型的な使い方

```yaml
- index: 5
  speaker: character_xxx
  voice: 'voicepeak:Miyamai Moca'
  pause_sec: 1.0    # セリフ後に 1 秒の余韻
  text: |
    そう。それだけのこと。
```

音声合成アプリ自身が「一拍空ける」を作れない場合があるので、カット側の表示時間を伸ばして無音区間を作る運用を想定しています。

## 6. 再生時の音声プリフェッチ

カット切替の瞬間に音声が一瞬途切れる現象を抑えるため、ライブプレビューは現カット再生中に **次のカットの wav を裏で先読み** します。再生開始時にも残り全カットぶんの wav を `<audio preload="auto">` で並列にロードします。

- TTS で再生成して URL が変わった場合、停止 / 再生時にプリフェッチキャッシュは破棄されるので、新しい wav が即時反映されます。
- 一度生成した wav は素材として `projects/<id>/assets/audio/tts/` 配下に残り続けます。不要になった分は **アセット管理** から削除してください。

## 7. 音声合成のトラブルシュート

### 「ボイスを登録」を押しても VOICEVOX が反応しない

- Engine の URL (`http://127.0.0.1:50021`) が正しいか確認。VOICEVOX の `設定 → エンジン設定` でポートを変えている場合は URL も書き換えてください。
- 自動起動でアプリ立ち上げに 20 秒以上かかる環境では、もう一度ボタンを押すか、VOICEVOX を手動で起動してから押し直してください。

### VOICEPEAK が検出されない

- macOS: `ls /Applications/voicepeak.app/Contents/MacOS/voicepeak` でファイルが存在するか確認。
- Windows: `C:\Program Files\VOICEPEAK\voicepeak.exe` (または別ドライブにインストールしている場合のフルパス) を「VOICEPEAK バイナリのパス」に明示。
- 旧バージョンや破損ファイルだと `--list-narrator` が空を返すことがあるため、VOICEPEAK 本体のアップデートを試してください。

### 「voicevox の voice_id を解決できませんでした」エラー

`voicevox:9999/タミラル` のように、カタログにない `voice` を指定したケースです。**ボイスを登録** を押し直してカタログを最新化するか、YAML の `voice` を実在する組み合わせ (例: `voicevox:春日部つむぎ/ノーマル`) に書き換えてください。

### 一括登録で一部のカットだけ感情が空になっている

VOICEPEAK の話者にその感情が無い場合、立ち絵システムは自動的に「ノーマル」にフォールバックします (合成自体は走り、wav は出力されます)。意図せずノーマルになっていたら、`/`-区切りの感情名と話者の組み合わせを確認してください。

### 同じプロジェクトで合成しすぎて assets/audio/tts が膨らんだ

`projects/<project_id>/assets/audio/tts/` を直接掃除しても問題ありません。プロジェクトのアセット管理ダイアログから個別削除も可能です。
